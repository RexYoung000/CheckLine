> 模式：Deep

## 一、页面类型与布局范式

| 页面 | 类型 | 布局范式 | 平台差异 |
|------|------|---------|---------|
| 主屏 | Dashboard | 预算钱包横滑 C 位 + 当前钱包列表 + 心愿轻提示 | iOS: 单列全宽；macOS: 居中卡片 |
| 预算详情 | List + Dashboard | 顶部进度条仪表盘 + 下方分类使用列表 + 流水 | 两端一致 |
| 归类弹窗 | Sheet/Modal | 从底部弹起，紧凑表单：金额 → 预算标签 → 分类 → 备注 | iOS: bottom sheet；macOS: popover |
| 预算创建 | Full-screen | 步骤式表单：模板 → 周期 → 金额 → 分类 → 策略 → 心愿 | 两端一致 |
| 心愿详情 | Detail | 顶部进度大圆 + 下方来源明细列表 | 两端一致 |
| 统计 | Dashboard + Calendar | 月度概览 + 预算 vs 实际 + 消费记录日历 | 两端一致 |
| 我的/设置 | Grouped List | 个人状态卡 + 财务管理 + 通用设置 | 两端一致 |
| 结算清单 | Full-screen | 信息密度高：总览 → 关联账 → 结余 → 分配 → CTA | iOS: 全屏；macOS: 窗口 |
| 结算高光 | Full-screen overlay | 全屏动画覆盖，无导航 chrome | 两端一致 |

## 二、组件策略

### 核心组件库

| 组件 | 用途 | 出现位置 |
|------|------|---------|
| **BudgetCard** | 预算卡片：名称 / 剩余 / 进度条 / 时间 | 主屏、预算列表 |
| **BudgetBar** | 预算消耗进度条：线性 + 分色段 | BudgetCard 内 |
| **WishProgress** | 心愿进度：圆形进度环 + 大数字 | 主屏副位、心愿详情 |
| **CategoryPill** | 分类标签：图标 + 名称 + 金额 | 归类弹窗、预算详情 |
| **ExpenseRow** | 流水行：金额 / 分类 / 时间 / 备注 | 预算详情、结算清单 |
| **BudgetTagChip** | 预算标签 chip：选择/取消 | 归类弹窗 |
| **SettlementCard** | 关联账确认卡片 | 结算清单 |
| **DistributionSlider** | 心愿分配条：拖拽分金额 | 结算清单 |
| **CelebrationOverlay** | 庆祝覆盖层：全屏动画 | 结算高光、心愿达成 |

### 组件设计原则

1. **卡片为主** — 圆角统一 16pt，轻阴影，信息密度控制在一屏内
2. **进度条为第一公民** — 不是装饰，是可交互的视觉主体
3. **chip/tag 组件** — 平等标签的 UI 载体，选中的有填充，未选中的镂空
4. **大数字字体** — 剩余金额用 Display 字号，像 Copilot 那样

## 三、响应式行为

| 断点 | 布局 |
|------|------|
| iPhone (紧凑宽) | 单列全宽，TabView 导航 |
| iPad (常规宽) | 双列：侧栏导航 + 内容区 |
| Mac (窗口) | NavigationSplitView，最小窗口 400x600 |

---

## 四、密度与扫读模型

- **主屏**：低密度。最多 3 块信息区，留白充足
- **预算详情**：中密度。进度条 + 分类摘要 + 流水列表
- **结算清单**：中高密度。大量信息需在同一屏呈现但不拥挤
- **归类弹窗**：低密度。每个字段独立行，大面积触控目标
