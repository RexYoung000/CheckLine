# Stage 2b-5 · 内容报告

> 模式：Deep

---

## 一、产品声音

**调性**：温柔但有边界。像朋友在提醒，不是银行在通知。

| 不能说 | 应该说 |
|--------|--------|
| 省钱 / 省了 ¥XX | 离心愿近了 ¥XX |
| 超支 / 超出预算 | 今日预算用完了 |
| 记账 / 录入流水 | 记一笔 |
| 扣血 | 记下这笔 / 已用 / 最近记录 |
| 主预算 / 副预算 | 这笔归到哪些预算 |
| 余额 / 剩余额度 | 还能花 ¥XX |
| 失败 / 错误 | 出了点小问题 |

## 三、错误与异常文案

| 场景 | 文案 |
|------|------|
| 金额为 0 | 「请输入金额」 |
| 未选预算 | 「选择至少一个预算」 |
| 未选分类 | 「选择一个分类」 |
| 心愿分配总和不等于结余 | 「分配金额总和应为 ¥600」 |
| iCloud 未登录 | 「iCloud 未开启，数据仅保存在本机」 |
| 网络错误 | 「出了点问题，自动重试中」 |
| OCR 失败 | 「未识别到金额，请手动输入」 |
| 语音失败 | 「没听清，再说一次试试？」 |

## 四、CTA 策略

| 位置 | CTA | 样式 | 时机 |
|------|-----|------|------|
| 主屏空状态 | 「创建预算」 | 大号填充按钮 | 首次启动 |
| 主屏 | 「+」记一笔 | 底部浮动圆按钮 | 始终可见 |
| 心愿区空 | 「设个心愿」 | 中等填充按钮 | 未建心愿时 |
| 结算清单底 | 「触发结算高光」 | 大号庆祝色按钮 | 结算时 |
| 心愿达成后 | 「开新心愿」 | 中等填充按钮 | 达成后 1 秒 |
| 付费墙 | 「解锁全部功能」 | 大号填充按钮 + 试用提示 | 触发限制时 |
