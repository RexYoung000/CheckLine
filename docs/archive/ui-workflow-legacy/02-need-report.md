## 一、产品定位

「预算线」不是传统记账 App，也不是单纯存钱 App。它是**「时间 + 主题」预算容器 + 心愿燃料系统**。

新版 UI 使用「预算钱包」结构承载这些预算容器：用户看到一个个独立钱包，但产品心智仍是 CheckLine 的「线 / 界限 / 检查」。

定位一句话：**别的地方记账是看「钱去哪了」，预算线是看「离心愿还有多远」。**

---

## 二、用户画像

### 核心用户：小陈

- 28 岁，产品经理，月薪 ¥20K
- 每月固定花 ¥10K（房租 ¥4K + 伙食 ¥2K + 交通 ¥1K + 娱乐 ¥3K）
- 已经在用支付宝小荷包把工资分成几个「袋子」
- 想过记账，但坚持不到两周——只记不控没意义
- 有一个明确的心愿：攒 ¥12K 去京都看樱花
- 希望看到「省下的钱自动变心愿进度」，而不是「这个月又超支了」

### 用户任务优先级

| 优先级 | 任务 | 频次 |
|--------|------|------|
| P0 | 看主预算还剩多少 | 每天 2-3 次 |
| P0 | 记一笔 | 每天 3-5 次 |
| P0 | 看心愿进度 | 每周 2-3 次 |
| P1 | 创建预算 | 每月 1 次 |
| P1 | 结算确认 | 每周期 1 次 |
| P1 | 创建心愿 | 每 2-6 个月 1 次 |
| P2 | 心愿达成庆祝 | 每 2-6 个月 1 次 |
| P1 | 统计/消费日历回看 | 每月 1 次 |

## 三、核心页面清单

| 页面 | 作用 | 层级 |
|------|------|------|
| **主屏（Home）** | 当前主预算 C 位 + 心愿进度 + 其他预算入口 | 首页 |
| **预算详情** | 单个预算的完整视图：分类使用 / 流水 / 设置 | 二级 |
| **归类弹窗** | 记一笔的核心交互：金额 / 多预算标签 / 分类 | 模态 |
| **预算创建** | 选模板 → 周期 → 分类 → 超支策略 → 默认心愿 | 模态/全屏 |
| **心愿详情** | 心愿进度 / 来源明细 / 设置 | 二级 |
| **心愿创建** | 名称 / 目标金额 / 图标 / 颜色 | 模态 |
| **统计概览** | 月度概览 / 预算 vs 实际 / 分类分析 | 一级 |
| **消费记录日历** | 月视图 / 点日期看记录 / 预算标签 | 统计内 |
| **结算清单** | 关联账确认 + 结余分配 + 触发高光 | 全屏 |
| **结算高光** | 强动画庆祝页 | 全屏覆盖 |
| **心愿达成** | 全屏庆祝 + 分享 | 全屏覆盖 |
| **我的/设置** | 个人状态 / 预算设置 / 通知 / 外观 / 付费 | 一级 |

## 四、状态覆盖

每个页面必须覆盖：

| 状态 | 主屏示例 |
|------|---------|
| **空状态** | 首次使用：引导创建第一个预算 + 第一个心愿 |
| **加载中** | SwiftData 同步中，进度条骨架屏 |
| **正常** | 预算剩余 ¥1,520，心愿 65% |
| **边界** | 预算刚好用完（¥0）、心愿即将达成（99%）、多预算并存 |
| **错误** | iCloud 同步失败、OCR 识别失败 |
| **庆祝** | 结算高光、心愿达成 |

## 五、平台差异化

| 特性 | iOS | macOS |
|------|-----|-------|
| 首屏入口 | TabView 底部 | NavigationSplitView 侧栏 |
| 速记 | 锁屏 Widget | 菜单栏图标 + 全局快捷键 |
| 截图识别 | Photos 监听 | 剪贴板监听 |
| 结算高光 | 全屏动画 + Haptic | 窗口动画 + 无 Haptic |
| Widget | 多种尺寸 | 通知中心 Widget |

## 七、Stitch 原型要求

- 必须覆盖完整 App：首页、预算、心愿、统计、消费日历、我的、记一笔、结算、心愿达成。
- 参考旧 Stitch「预算钱包」工程的结构 feel：简洁卡片、清晰列表、统计图表、设置分组。
- 不照搬旧项目文案和品牌；品牌升级为「预算线 / CheckLine」。
- 用户可见文案不出现「扣血」。
