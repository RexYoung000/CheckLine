# CheckLine 全 App Stitch 生成 Brief（v2）

> 这份 Brief 是 CheckLine 完整 App 高保真原型的生成指南。
> Stitch 应该独立读完这份文档就能产出 14 页完整原型，不需要回头查其他文档。
> 如有冲突，以本文为准；如有遗漏，参考 `docs/spec/PRD.md` / `docs/design/DESIGN.md` 兜底。

## 一、生成目标

为「**预算线 CheckLine**」生成一套完整 iOS App 高保真原型，覆盖 14 个核心页面 + 关键交互动效 + 全部空状态。

**输出范围：**

- 14 个页面（含教程、设置、通知设置）
- 主要交互动效（钱包横滑、记一笔、结算高光、心愿达成、教程翻页）
- 全部空状态设计
- 线条小助手 IP 在关键节点的出场

**不输出：**

- 不输出代码（仅原型）
- 不照搬旧预算钱包项目的品牌或文案
- 不出现「扣血」「记账」「主预算 / 副预算」「AI 智能记账」

### 2.2 可借鉴（feel 层面）

- **一眼看懂当前钱包状态** — 信息层级清晰
- **卡片与列表干净** — 信息不堆叠
- **操作入口克制** — 首页不放并列大按钮
- **大数字 + 简洁图表** — 统计页不做复杂财务报表
- **分组列表** — 设置页安静、清晰、可扫读

### 2.3 不能继承

| 不能继承 | 原因 |
|---------|------|
| 真实账户余额工具的定位 | CheckLine 是预算控制 + 心愿激励，不是银行账户 |
| 「AI 智能记账建议」概念 | 与 CheckLine「克制」核心心智冲突 |
| 真实用户头像/姓名/ID | 用 sample 虚构数据 |
| 「钱包」压过「预算线 / CheckLine」品牌 | 钱包是 UI 容器，品牌是预算线 |
| 「扣血」等用户可见文案 | CheckLine 用「记下这笔」「已用」「最近记录」 |
| 旧项目的色彩与字体 | CheckLine 走「深空暖金」主题，见第四节 |

## 三、产品心智

| 维度 | 内容 |
|------|------|
| 中文名 | 预算线 |
| 英文名 | CheckLine |
| 一句话定位 | 给自己划一条线，线内自由，线外克制 |
| 核心隐喻 | 「线」= 边界 + 检查点 |
| UI 容器 | 预算钱包（每个钱包对应一个独立预算） |
| 情感闭环 | 预算结余 → 心愿基金 → 用户离心愿更近 |
| 北极星指标 | 单用户月度心愿基金累积金额 |

**六条核心心智（不能动的内核）：**

1. 预算 = 时间 + 主题
2. 多预算平等并存（一笔消费可同时归属多个预算）
3. 支出 = 预算消耗（视觉可感）
4. 省下 = 心愿燃料
5. 结算 = 高光时刻
6. 结余分配权归用户

**不做清单（避免 Stitch 跑偏）：**

- 不做多人 AA 分账
- 不做银行卡/支付宝自动同步
- 不做复杂财务报表
- 不做社交关注/排行榜
- 不做 AI 推荐「该买什么」
- 不做「主预算/副预算」层级

## 十三、无障碍底线

### VoiceOver

- 所有图标按钮必须有 accessibilityLabel
- 金额读完整文本：「还能花一千五百二十元」，不读「¥1,520」
- 进度条 accessibilityValue：「百分之七十」
- 装饰性插图 accessibilityHidden(true)

### Dynamic Type

- 正文使用语义字号 .body / .headline 等
- display 大数字可固定字号但加 minimumScaleFactor(0.5)

### 触控目标

- 最小 44×44pt
- chip / pill 视觉可小于 44pt，tap area 必须 ≥ 44pt

### 对比度

- 正文 ≥ 4.5:1，大文字 ≥ 3:1（WCAG AA）
- 信息不能单靠颜色，进度条数字+图标辅助
- 暗黑模式所有语义色单独验证
