# CheckLine 全 App Stitch 生成 Brief

## 目标

为「预算线 CheckLine」生成一套完整 iOS App 高保真原型。

这次不是单页首页优化，而是完整 App UI / 交互动效方案。原型需要覆盖首页、预算、心愿、统计、消费日历、我的/设置、记一笔、结算和心愿达成。

## 产品心智

- 中文名：预算线
- 英文名：CheckLine
- 核心隐喻：给自己划一条消费边界，随时检查离这条线还有多远。
- UI 容器：预算钱包。一个预算钱包对应一个独立预算。
- 情感闭环：预算结余让用户离心愿更近。

## 视觉方向

- 参考旧 Stitch「预算钱包」工程的结构 feel：清晰、简洁、轻快。
- 保留 CheckLine 的高级感：克制、有边界、温柔、面向心愿。
- 不要通用 AI 感：避免无意义渐变、过多圆形发光、过多并列按钮。
- 线条小助手作为轻量 IP：线、节点、检查点、小表情，不做重角色。

## 底部导航

使用 5 个 Tab：

1. 首页
2. 预算
3. 心愿
4. 统计
5. 我的

「记一笔」是浮动主操作，不占底部 Tab。

## 页面清单

### 1. 首页

结构：

- 顶部：日期 + CheckLine / 预算线 + 设置入口。
- 主区：预算钱包横滑卡片。
- 卡片内容：预算名称、周期、还能花、已用比例、分类摘要。
- 下方：当前钱包列表，随横滑切换同步变化。
- 心愿：轻量展示一个相关心愿。
- 主操作：一个清晰的「+ 记一笔」入口。

禁止：

- 不要在首页放「结算 / 心愿 / 统计」三枚并列大按钮。
- 不要出现「最近扣血」。

### 2. 预算

结构：

- 顶部总览：全部预算钱包概览。
- 列表：预算钱包卡片。
- 详情入口：查看单个预算钱包。
- 新建入口：新建预算钱包。

预算详情：

- 当前还能花多少。
- 已用进度。
- 分类列表。
- 最近记录。
- 结算入口。

### 3. 记一笔

使用 bottom sheet。

字段：

- 金额
- 归到哪些预算
- 分类
- 备注
- 主按钮：「记下这笔」

动效：

- 提交后 sheet 下沉。
- 当前预算钱包金额数字滚动变化。
- 进度条平滑缩短。

### 4. 心愿

页面：

- 心愿列表
- 心愿详情
- 新建/编辑心愿
- 心愿达成反馈

心愿达成：

- 全屏庆祝。
- 线条小助手出现。
- 文案表达「心愿解锁了」和「离心愿更近」。

### 5. 统计

统计模块包含消费日历。

结构：

- 月度大数字：本月离心愿近了多少。
- 预算 vs 实际：简洁柱状图。
- 分类分析：按分类显示占比或金额。
- 消费记录日历：月视图。

消费日历：

- 日期上有记录标记。
- 点选日期后，下方显示当天记录。
- 每条记录显示所属预算钱包标签。
- 支持「全部预算 / 当前预算」切换。

### 6. 我的 / 设置

参考旧 Stitch 设置页的分组列表。

结构：

- 个人状态卡：预算达标率、连续使用、心愿摘要。
- 财务管理：预算设置、记录管理、导出。
- 通用设置：通知、外观、货币、iCloud 同步。
- 订阅与关于：版本、隐私、解锁全部功能。

### 7. 结算

页面：

- 结算清单
- 关联账确认
- 结余金额
- 心愿分配
- 结算高光

动效：

- 结算确认后进入全屏高光。
- 数字骤变。
- 轻量粒子。
- 线条小助手作为检查完成的反馈。

## 文案规则

必须使用：

- 记一笔
- 记下这笔
- 还能花
- 已用
- 最近记录
- 离心愿近了
- 预算快用完了

禁止用户可见：

- 扣血
- 超支
- 记账
- 主预算 / 副预算
- AI 智能记账建议

## 交互动效

- 钱包横滑：snap 到当前钱包，下方列表同步淡入切换。
- 记一笔：金额数字滚动、进度条缩短、轻 Haptic。
- 统计：图表切换轻量过渡。
- 日历：选中日期放大/高亮，下方记录列表切换。
- 设置：列表点击轻微缩放或高亮。
- 结算：全屏高光，数字骤变。
- 心愿达成：比结算更强的庆祝，但不要浮夸。

## 输出要求

- 先生成完整 App 的页面集合，不只首页。
- 页面之间能体现基本点击/跳转关系。
- 保留旧预算钱包的清晰感，但品牌必须是 CheckLine / 预算线。
- 用户可见文案不出现「扣血」。
