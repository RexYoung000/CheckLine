---

## 使用原则

- 参考旧预算钱包的结构 feel：简洁卡片、清晰列表、轻量统计、分组设置。
- 不照搬旧项目品牌和文案；品牌升级为「预算线 / CheckLine」。
- 必须覆盖完整 App：14 页 × 全部空状态 + 动效。
- 用户可见文案不出现「扣血」。
- 线条小助手是轻量 IP，只在关键节点出现。

---

## brief 覆盖什么

主 brief 独立包含以下全部内容，Stitch 不需要跳出本文件查别的文档：

- 产品心智（六条核心 + 不做清单）
- 设计 Token（颜色 / 字号 / 间距 / 圆角 / 阴影 / 动效）
- 14 页详细规格（ASCII 线框 + 元素 + 文案 + 状态变体）
- 9 个组件规范（BudgetCard / TutorialCard / EmptyState 等）
- 4 类空状态设计
- 10 个关键交互动效
- 文案规则（必须用 / 禁止用）
- 线条小助手出场点
- 无障碍底线
- iOS / macOS 平台差异
- 输出优先级与跳转关系
