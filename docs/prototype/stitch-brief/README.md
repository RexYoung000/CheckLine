## 当前原型范围

必须覆盖：

1. 首页
2. 预算列表
3. 预算详情
4. 新建 / 编辑预算
5. 记一笔弹窗
6. 统计概览
7. 消费记录日历
8. 我的 / 设置

可选覆盖：

- 结算清单
- 结算完成反馈
- 教程卡片
- 空状态页面（无预算、无记录、无统计数据）

不进入当前原型：

- 心愿列表
- 心愿详情
- 心愿达成反馈
- 结算转心愿分配

---

## 使用原则

- 以旧预算钱包的浅色卡片、清晰列表、轻量统计和分组设置为主参考。
- 品牌升级为「预算线 / CheckLine」。
- 用户可见文案不出现「扣血」。
- 不出现「主预算 / 副预算」。
- 不出现「AI 智能记账建议」。
- 不把 CheckLine 做成真实账户余额工具。
- 首页只保留一个清晰的「记一笔」主入口，不堆并列大按钮。
