# 2026-10-02 原生信息减负与区块布局验证

本轮直接调整正式 App 的展示层，依据 Rex 对两张减负稿的明确反馈：减少重复文字、长竖排目录和细线，让主金额、当前任务与下一步更容易找到。保留四 Tab、液位卡、紫色材质和小朵，金额计算、草稿及确认门禁沿用已有服务。代码完成，以下具名任务在模拟器验证；最终审美与真机使用体验尚未验收，M4 保持开放。

## 已实现与验收路径

| 场景 | 当前表现与操作路径 |
| --- | --- |
| 预算概览 | 首页／预算点卡 → 主金额 → 已用／预算上限合组 → 待确认数量与金额 → 主要行动 → 记录、日历、历史、信息管理区块。普通说明按需展开，目录仍逐级返回。 |
| Agent | 右侧小朵或「记一笔」→ 放大的小朵与任务气泡 → 自然示例 → 语音／发送。删除重复身份、预算名、本地模式和能力标题；当前预算确有歧义时在气泡明确对象，确认字段完整保留。 |
| 语音入口 | 点击麦克风 → 明确未接通提示 → 关闭后原文字仍在 → 可切手动。没有模拟录音、转写或索权；输入框长按仍供系统文本选择。 |
| 创建与手动 | 预算页创建默认表单，名称／金额与币种／周期和生效日期合组；手动消费的金额、商家、归属、日期默认可编辑，补充内容按需展开。Agent／手动切换及跨重启草稿不丢字段。 |
| 消费详情与日历 | 记录 → 待确认 → 详情，原始币种随主金额展示，归属／来源／状态合组，确认对象明确；返回恢复筛选。日历切到周期外显示「所选日期不在本周期」，不会将该日表示为零消费。 |
| 其他页面 | 心愿清理重复添加入口，合组条目与钱包信息，保留虚拟钱包和待恢复差额；分析标明所选周期；来源按可用／未接通分组；设置收敛重复说明并适配大字。结算核对保留全部金额与覆盖缺口。 |

常规字号使用两列预算目录，大字号改为单列；小朵与气泡在大字号时纵向排列并可滚动。关闭、更多、切换、语音与发送保持完整触控范围，输入内容仍随系统字号变化。英文示例使用当前理解器支持的 CNY，而不是无法解析的币种别名。

## 修复与边界

- 首轮编译中的参数顺序错误，以及并行编辑未完成文件导致的临时缺失辅助类型，已修正并重新构建，没有把失败运行计为通过。
- 小屏最大辅助字号下发现标题图标、示例和操作区拥挤：控件保留触控尺寸，图标采用固定可辨字号，示例缩短，小朵／回复置于滚动正文，输入文字不缩小；定向用例和截图复查通过。
- Release 保留既有两处 actor 隔离警告及一处未使用预览警告。部分输入任务结果包记录 `Invalid frame dimension (negative or non-finite)`：另用改动前 `5d96a20` 构建，在同一 iPad、同一英文输入用例中复现，测试也通过，表明该路径的警告不是本轮新增。[基线结果摘要](evidence/2026-10-02-ui-cleanup/baseline-ipad-test-summary.json)保存了对照；警告没有给出可定位的源码栈，具体根因仍未确认，不宣称已消除。
- 本轮没有物理 iPhone／iPad 操作、帧耗时测量、全页 VoiceOver 焦点巡检或所有横竖屏组合。iOS 17 仅经最低部署目标编译；来源／设置等次级页面主要做代码与文案检查，不能将关键任务测试扩展为全 App 验收。
- 语音识别、云端 Agent、图片识别、被动来源、真实账单导入和新增业务管理未接通；现有隔离演示不能代替这些能力的功能验收。

Rex 可运行 `CheckLine Demo`，按「点预算卡→查看区块→待确认记录→确认归属→逐级返回；记一笔→输入→语音提示→手动切换→关闭／重开；预算页创建；心愿／分析／设置」检查本轮表现。`CheckLine App` 使用本机持久化，测试运行器 `Check_LineUITests-Runner` 不是供日常打开的 App。
