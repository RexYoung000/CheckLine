# CheckLine 高保真交互原型

打开 [index.html](index.html) 查看原型，或打开 [capture.html](capture.html) 查看全部浅暗画面。无安装依赖；双击 HTML 可离线打开。审阅壳的桌面与手机窗口均可用，手机画面基准为 402 × 874。

本轮依据当前原生版本 `a7875ba` 和 2026-10-27 冰蓝浅暗设计契约，提供 31 个核心页面、48 个补充状态，浅暗共 158 个画面。页面选择、三条流程入口和主题切换均在手机画面外。

## 主要验收路径

1. 记一笔 → 保存：新增咖啡40，已确认1680→1720、原待确认40不变、暂计剩余1280→1240。
2. 待确认 → 结算：确认原有40，已确认1720、待确认0、剩余1280；勾选核对范围后结算，钱包860→2140，下期仍于12月1日开始。
3. 心愿 → 耳机卡 → 翻面 → 兑换：核对真实成交699，勾选真实购买后确认，钱包860→161，进入已实现收藏。

左侧／手机顶部的页面选择器可查看草稿恢复、保存失败、可能与确定越线、额度调整预览、差额恢复、缺汇率、兑换不足、首次云端许可等独立状态。

## 维护来源

- `screen-model.js`：核心页面和组件组合；Figma 图层与浏览器复用该模型。
- `states.json`：补充状态唯一编辑源。`states.js` 是用于离线打开的生成副本，按 `window.EXTRA_STATES = <JSON>;` 同步。
- `adapter.js`、`style.css`：将设计模型展示为 DOM，并提供审阅导航、缩放和键盘操作。
- `assets/`：预算卡与小朵的项目自有 SVG，按原生源码生成的静态近似。

## 交互边界

这是固定合成示例的点击原型。表单可滚动但不可编辑，不保存账本；明确标有“回到示例起点”的操作会重置演示场景。系统设置、照片和权限等动作只显示占位说明。不调用云端、不传输真实账本、不执行购买。

心愿显示比例遵循现有 WishCoverage：未达标向下取整，最多99%；达到真实 Decimal 金额门槛后显示100%。结算以已确认支出计算，“接受当前数据”不等于确认待处理记录。

本轮以 iPhone 设计为主；浏览器窗口适配不是 iPad 原生版设计验收。原生液体、手势、触感、语音、真实服务及持久化另行验收。新增设计表达待 Rex 确认。
