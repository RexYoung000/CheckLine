# 模拟器试用前交互检查

范围：基于 `9041b7d` 的原生 SwiftUI 页面与演示数据，沿用已确认的液面卡片、卡夹和原生玻璃导航。不重新选视觉方向，也不将完整 V1 的缺项算成本轮已交付。

## 查出的实现问题

| 级别 | 场景与证据 | 影响 | 修复与验证要求 |
|---|---|---|---|
| 阻塞 | `CheckLineWorkspace` 创建心愿、置顶后保留旧 `UndoToken`；`UndoCoordinator` 恢复整份快照；旧撤销路径保存失败仍写成功提示 | 撤销旧记录可能抹掉后续心愿或顺序，保存失败被误报 | 下一次成功写入废止旧撤销；仅查询保留。增加跨操作、失败与重试、持久化回归 |
| 重要 | `AgentTaskPanel` 已识别金额时隐藏金额；`confirmStructured` 仅在原金额为空时读取补填币种 | 不能核对结果；已识别金额但缺币种时确认失败；修改值可能不被采用 | 始终展示结构化字段，提交可见值；验证缺币种、补金额、修改金额和取消 |
| 重要 | 非结构化追问也显示确认按钮，处理函数却直接返回 | 按钮无反应 | 追问只保留输入；有可提交草稿才展示确认 |
| 重要 | 表单与 Agent 共用 `banner`；换讨论对象只改 ID | 旧回复可能出现在表单或新卡名下 | 分开反馈，显式切换清除旧结果；验证返回和切换 |
| 重要 | 预算概览通过替换 `section` 打开记录 / 日历 | 没有返回概览的路径，只能关闭重进 | 使用原生导航层级；验收返回 / 关闭路径 |
| 优化 | 创建预算不改变当前选择；抽卡使用仅在 `onEnded` 清零的持久偏移 | 创建后仍看旧卡；手势中断可能残留偏移 | 选中新卡；临时手势状态自动复位、限制纵向和单卡边界 |
| 优化 | `LiquidBudgetCard` 的 `flows == false` 把相位置零 | 打开、关闭面板时液面突跳 | 暂停 / 继续同一相位；验证周期接缝及后台恢复 |
| 优化 | 375 pt 原生确认页仍展示完整介绍和重复输入区 | 确认操作落在首屏外 | 确认时升为大面板并收拢介绍与输入，金额 / 币种并排；英文小屏截图确认按钮与取消可见 |

以上问题已完成代码修复；另外明确创建表单的当前重复方式为「每月循环」，大字体日历日期改变时同步月份标题。验证完成范围如下，不新增业务目标。

## 仍需区分的产品缺项

- 完整预算编辑 / 删除、已有待确认记录处理、检查式结算 UI 尚未交付；当前待确认页只能查看。
- 心愿同币种购买确认已接领域服务；跨币种汇率输入、退款界面尚未交付。
- Agent 当前是本地文字解析与查询，不具备云端多轮对话、语音、图片识别或被动来源。
- 分析日期属于当前展示周期，不代表完整历史周期回看。

## 原生玻璃底栏修正

- 原底栏给整个 HStack 应用 `glassEffect`，选中态仍是固定灰色 Capsule，缺少原生分段控件的选中透镜与跟手处理。iOS 26+ 改由系统底部工具栏承载图标 Picker，以原生工具栏间隔分开 Agent；低版本保留原 material 回退。
- 预留系统分组内边距，避免 iOS 27 将四个入口折叠进“更多”；预算、心愿与记录详情显式隐藏底部工具栏。尺寸从当前容器直接取得，避免切页后才测量造成宽度跳变。
- 构建通过；4 项 `WalletNavigationTests` 专项回归通过，结果 `/tmp/checkline-glass-navigation-tests.xcresult`。新截图覆盖 iPhone 18 Pro / iOS 27、375 pt iPhone SE / iOS 26.5 英文首页与 iPad mini / iOS 27 英文预算页，四入口及独立 Agent 均可见。12 秒原生自动导航录屏及逐帧抽样未见入口折叠或底栏消失。
- 本轮材料：`tmp/native-ui-2026-09-22/glass-restoration/`。上述验证不包含真实按压、拖动选中、VoiceOver 或系统玻璃偏好切换；Device Hub 的触控连接仍超时。
