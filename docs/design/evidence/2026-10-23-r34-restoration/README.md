## Rex 验收路径

1. **首页与插拔**：在预算首页长按前卡，检查卡尾抬离、摘要变为断联占位；点卡面重新插入，检查下降→接触反冲→卡口定点 CLICK，以及 0.8 秒沿组件圆角边缘传导、数字与票据同步。插稳后再单击进入预算抽屉。多张预算时左右甩动，检查下一张真实预算晋升、旧卡回到后叠层。
2. **层级与返回**：拖卡夹边缘上拉，卡片与卡夹共同跟手，最终仅留名称／金额／横向液位透窗，记录自然接在下方；小幅拖动松手回弹。点击边缘空白不切层，返回按钮跟随横窗下缘。记录列表内部滚动不应改变层级。
3. **卡库**：下拉卡夹或点下按钮，默认弧线。点侧卡先聚焦、再点中卡使用；切到球面后上下和左右浏览都保留卡库，滑出后原卡能循环浮现。拖底部下箭头返回；单点拖动面不返回。卡库显示记录图标集合、未显示数量及已消费值。
4. **心愿与封面**：检查前两张小卡并列、奇数末卡横铺，切横条后不丢心愿；点右上展开到暗遮罩大卡，拖动或轻点翻面。正面仅名称／封面／价格，背面以百分比和兑换为主；未定价兑换不可用。封面切换只更新预览，照片可嵌入／铺满并调整焦点。
5. **奖励**：在需要时由用户主动核对并确认购买或正式结算。购买后观察同位蓄压、自然裂纹、厚玻璃碎裂、原封面揭晓和已实现结果；正结算保留当前页，六波金币进入心愿余额，最终金额精确。跳过、关闭或切后台应落稳同一已保存结果，不重复提交。
