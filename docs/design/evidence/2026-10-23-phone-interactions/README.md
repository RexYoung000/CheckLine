# 手机交互反馈修复 · 2026-10-23

本轮对应 Rex 在 1.0（10）真机体验中反馈的四项功能问题；底栏聚拢排版按 Rex 意思留待讨论。原生实现继续采用 R34，未改导航结构、账本 Schema、金额规则或服务器。

## 修复与原因

- **长按与拖卡**：原卡面上的长按、拖拽会共同改变识别器所在视图的位置。只换全局坐标仍有长按结束后误回插的失败；现合并到固定的预算舞台触控层，一次手指接触负责轻点、长按和拖动，移动后取消待触发的长按任务。
- **卡库返回**：原下箭头是不可点击的图形；返回还会先把父层进度重置到展开态。现在箭头是独立按钮，弧线中央下拖、边缘及底部空白可拖回；周围轻点不返回，球面中央仍保留双轴浏览。侧卡聚焦和选择继续分开。
- **消费删除**：详情新增入口，展开记录恢复原生左滑。两处进入同一核对，展示删除后预算余量；确认前不改数据。普通未结算购买可删除；已结算、退款相关和心愿购买沿用现有保护。陈旧确认拒绝并可重新核对；保存失败保留记录和附件。成功才清理附件，不清空另一个 Agent 草稿。
- **常驻气泡**：原气泡在整张卡范围取样，被液面裁掉后所剩很少，拔卡还会停掉液体。现在 22 个气泡在实际液体体积内错相循环；与短时插入喷涌独立，竖卡、横窗和拔卡后继续。减少动态效果保持静态。

原生左滑初次核对曾触发 UIKit 列表异常：预览入口误用 destructive role，系统提前移除行。已把红色左滑入口与真正的确认删除分开；失败记录保留，不以按钮出现算完成。恢复阅读位置也在此次回归中发现并修复，不删除或削弱阅读位置测试。

## 已运行与边界

- 232 项领域／状态测试、49 suites 已通过，包含手动删除持久化、钱包不变、保留 Agent 草稿、保存失败、陈旧核对、受限记录和气泡体积／持续性。
- 26 个不同 UI 用例在分组回归及修复重跑中均有通过记录，包含持续长按、弧线／球面、真实删除、Agent 草稿、心愿兑换／结算、VoiceOver 遍历与减少动态效果；不是一次整组 26/26。最初 UI1 10 项中 4 项失败，随后 UI2 10/10；兼容组 16 项中 14 项先通过，另两项（AX 定位及阅读位置）修正后分别重跑通过。

- 签名 Release 1.0（11）构建及校验通过，已覆盖安装到 iPhone 12；设备查询确认为 1.0（11），正常无演示参数启动及随后进程检查成功。未卸载或清空数据，未重置连接。
- 使用隔离合成账本自测；未删除真实手机记录，未读取个人账本／Keychain 内容，未发真实云端请求。

## 手机上怎么核对

1. 预算首页按住卡面超过半秒，继续缓慢下拖／上拖，停住手指后松开；不应来回跳位。拔出后摘要断联，轻点卡面重新插入。
2. 下拉进入卡库，试短拖取消、弧线卡片区域下拖、底部箭头点击和边缘拖回。球面中央上下滑仍用于找卡。
3. 上拉卡夹查看记录，左滑后点删除；先取消，再进入详情点垃圾桶核对并确认。只有最后确认才删除。返回首页再展开，阅读位置应保留。
4. 进入首页等待超过十秒，再拔卡等待几秒，检查液体仍有缓慢不规则气泡。减少动态效果开启时为静态表现。
