# 底栏浮在内容之上

2026-10-23 Rex 指出手机首页底部有灰色区域和水平截断，要求内容延伸到按钮后方。当前修复为1.0（17），保持真正系统UITabBar、纯图标、居中胶囊及独立小朵，不新增底板或分隔线。

## 变化

首页的88pt底部safeAreaInset提前缩短了整个场景，卡夹和票据在导航上方被裁断，露出背景形成硬边。移除该整页空区，让场景延伸到屏幕底边；摘要滚动视口同时限制在场景内。首页摘要、展开记录和心愿页将120pt避让放在滚动内容末端，允许内容经过玻璃后方，又能把最后一项完整滚到控件上方。

卡库的操作区域独立避开浮层，背景继续延伸。没有更改系统透镜、按钮位置、图标、金额、账本、草稿、权限或网络行为。

## 验证

- 主模拟器402pt／iOS27：纯图标居中／小朵、末条记录、系统双向横拖、保存录入返回四条初轮通过；卡库返回初轮失败，定位到延伸后的返回按钮与心愿Tab重叠。收正卡库操作高度后，末条记录与短拖取消／卡面拖回／箭头／边缘返回最终2/2通过。共5条不同用例具备通过记录，不能表述为一次整组5/5。
- 小屏375pt／iOS26.5：英文最大辅助字号、深色和应用减少动态开关的导航往返，及中文末条记录，2/2通过。iPad mini／iOS26.5：居中切页／小朵和末条记录，2/2通过。最后卡库避让修订未在这两种设备上另跑库返回，不扩大结论。
- 新增`testFloatingNativeDockKeepsLastRecordReachable`，使用已知最早的合成1000CNY记录，断言完整行位于浮层按钮上方且可点击，并实际打开消费详情。灰底是否消失仍通过实际截图检查，不能仅靠几何断言。
- 已检查首页、记录末端、心愿、小屏深色及iPad画面：底部没有跨全宽硬切，票据在玻璃下方连续，末条可滚离控件。原速模拟器片段已回看；不作为真机帧耗时证据。

## 手机与构建

初轮手机三条UI整组3/3通过：末条记录可达、系统双向横拖、保存录入／小朵返回。卡库避让修订后，Rex再次解锁，最终末条记录与卡库短拖取消／卡面拖回／箭头／边缘返回整组2/2通过。共4条不同真机用例具备通过记录，末条重复验证，不表述为一次5/5。

Release17及最终真机测试包构建通过，Release严格签名校验通过。测试结束后已原位恢复签名正式版，设备元数据确认`version=1.0`、`bundleVersion=17`；无演示参数正常启动成功，随后进程查询确认运行。未卸载、清账或重置配置，正式启动后没有截取个人账本画面。

本轮没有重跑金额领域全量测试。所有UI测试及画面使用隔离合成账本，未读取个人账本或Keychain、重置配置或请求真实模型；系统级减少动态、完整VoiceOver、真机帧耗时和最终手感／视觉另验。小屏大字只核对本轮底部导航和记录可达，不代表顶部工具栏等全页面字号适配通过。既有录入布局警告的定位边界见[16版补验](../2026-10-23-native-tab-glass/README.md#手机记录)，不宣称无运行时警告。
