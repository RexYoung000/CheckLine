# CheckLine 月度日期设置 · 2026-10-13

已在正式原生 App 实装完整月周期和按月重复的指定区间。签名 Release **1.0（7）** 已原位安装到 iPhone 12，设备版本查询及不带示例参数的正常启动成功。没有卸载、清空或读取用户账本；没有在手机代填或提交预算。M4 与 Rex 的最终体验验收保持开放。

规则由 Rex 确认：指定区间允许间隔，范围外消费不计入该卡。旧预算保留原规则与历史。金额仍是每期额度，不按天数折算；账本 Schema、金额算法、权限及网络边界不变。

## 验收入口与预期

预算页 → 创建预算卡 → 每月循环：

| 操作 | 预期 |
| --- | --- |
| 完整周期，开始日 15 | 每月 15 日至下月 15 日前；临界日属于新一期。1 日对应自然月。 |
| 指定区间，5～20 日 | 每月重复，包含 20 日；21 日至下月 4 日在这张卡之外。 |
| 指定区间，20～5 日 | 明确标为次月结束；今天在间隔内时预览下一段并显示尚未开始。 |
| 选择 29～31 日 | 短月临时取月底，原选择保留；下一月恢复原日，两期不重复归属。 |
| 每月循环 ↔ 一次性，手动 ↔ 小朵 | 名称、金额、币种与月度规则保留；表单切小朵直接核对已有字段。继续输入“改成500元”只更正金额。 |
| 关闭重开或退出 App 重启 | 恢复本机输入并重新计算实际日期，不恢复对话或自动创建。 |
| 创建完成 → 卡片信息与管理 | 显示重复规则及该期实际日期；额度编辑仍对本期和以后各期生效。 |

区间外归属和队列校验由领域／任务测试验证：不能绑定到该期或进入该卡队列，可选择其他预算或未纳入；结算后只纳入下一期有效范围，更远未来记录继续等待。没有在手机执行消费、结算或钱包操作。

## 状态与恢复

| 状态 | 转换和反馈 |
| --- | --- |
| 输入缺名称／无效金额 | 保存保持禁用，显示对应提示；日期设置即时预览，不写账本。 |
| 选择规则／起止日 | 即时更新完整日期、次月标记和必要说明；大字号用原生菜单并可滚动。 |
| 切换模式或继续修改 | 同一份任务输入保持，小朵核对不把表单拼成文字重新解析。 |
| 关闭／重启恢复 | 按任务隔离恢复；保存前重算当前或将开始的周期。日期已变化时不沿用旧核对结果。 |
| 条件不满足或保存失败 | 保留输入；现有错误、重试与放弃门禁继续有效。 |
| 保存成功 | 创建稳定标识的预算和周期并清理草稿；以后沿原选定日生成新一期。 |

## 修复与保留限制

初轮原生菜单未显示独立起止标签，已补齐。表单切小朵曾重新解析生成句子，使英文名称被缩短；现改为直接核对用户字段，连续修改金额及保存均复测通过。大字号额度标签改为分行，表单输入使用独立焦点。

测试本身也曾点击底部提示后方的离屏输入、快速拖动越过目标，或未滚动到原生菜单的目标日。已改为在可见正文内缓慢触摸滚动、停稳并检查字段及保存结果，小屏和 iPad 各自复测通过。部分早期结果收集被中断，以及没有执行用例的多设备启动尝试均不计入最终通过数。

既有 **`Invalid frame dimension (negative or non-finite)`** 输入警告仍存在，不能标为已修复。最大辅助字号每屏可见内容有限，已验证滚动选择及提交；不据此宣称全 App 排版完善。全 App VoiceOver、所有横竖屏、iOS 17 实际运行、真机语音和触摸动效未在本次切片重验。云端模型、真实导入及来源连接没有新增。
