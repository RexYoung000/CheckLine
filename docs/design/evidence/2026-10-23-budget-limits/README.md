# 全部预算卡上限编辑 · 2026-10-23

Rex 明确选择「统一支持所有预算卡」：一次性改本次，循环卡改本期及以后，已结算历史保持原值。本轮延续原生 R34，不改账本 Schema、币种、名称、周期规则或心愿钱包算法，也没有接入新的服务。

## 实现

- 取消上限编辑的仅月度限制，适用一次性、每周、自定义天数和月度规则族。只允许该卡当前未结算周期，草稿／归档卡、已结算历史及其他周期不可直接改写。
- 详情「预算上限」区块右侧直接提供 44pt 编辑入口，信息页／已有菜单继续复用同一编辑面板。非月度信息不再误称「每月循环」。
- 一次性预览说明「仅本次」，循环卡说明「本期及以后每期」；显示真实起止日，无截止日明确标示。没有未来周期的一次性卡不展示未来额度。
- 先输入、预览旧／新上限和剩余、区分确定／可能越线，再确认保存。使用同一个 Decimal 服务和原子事务；取消不写账本，保存失败保留输入，陈旧／重复确认拒绝。成功后首页液位／剩余和结算预估使用新上限。
- 提前结算后的待开始期可以设置上限，下一期原开始日、录入和结算门禁保留；旧周期、结算快照及心愿余额不回改。
- 大字号预览中金额曾在小数点处换行，实际截图发现后改为保持一行并适当缩放；再次检查 375pt 英文最大辅助字号，金额完整且操作可滚动到达。

## 不读代码的验收路径

1. 点首页预算卡进入详情，在「预算上限」右侧点编辑图标；输入新上限，先看预览，再确认保存。
2. 一次性卡预览应只说明本次；循环卡应明确本期及以后。取消后重开保留输入，确认后详情／首页显示新值。
3. 可把上限调到已用以下，分别核对确定越线与待确认造成的可能越线；修改上限本身不改变心愿余额。
4. 打开结算预览，应按新上限计算。已结算周期保持旧值，提前结算后等待下一期的卡不能因调上限而提前录入或再结算。
