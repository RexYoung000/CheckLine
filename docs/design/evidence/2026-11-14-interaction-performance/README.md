# 2026-11-14 卡库、结算稳定性与性能检查

Rex 在 iPhone 12 / iOS 27.0.1 的 1.0（19）反馈卡库偶发下拉后整页不响应，并要求检查整体卡顿、结算动效及结果页跳动。本轮复用已接受的 UI 与速度，修复呈现与重绘路径，不更改金额、Schema、预算详情、结算核对样式或心愿碎玻璃。

## 已定位并修复

1. **卡库焦点重复刷新。** 卡库原先每次读取投影都重新取当前时间，带截止日期的 `cycleProgress` 改变整个卡面模型的相等性，再通过焦点回调写回父层。真实 SwiftUI 宿主测试中，同一有截止日卡打开后发布 21 次而触发测试熔断，模拟 4 次回弹刷新后到 25 次；无截止日对照稳定。修复为首页／卡库共享同一呈现日期的投影，并在账本任何写入后失效内存缓存。修复后静置和回弹不重复发布；同卡消费写入仍更新金额。这证明反馈路径存在并已切断，不等于已复现用户所有“整页卡死”情形。
2. **每帧重复扫描账本。** 旧卡面每次取值会按卡扫描所有周期和消费。当前一次确定展示周期并分组相关消费，动画重用内存投影。24 张卡、600 个周期、12,000 笔合成消费、20 次读取的模拟器样本：逐卡全扫 1.188 秒，分组冷读 0.081 秒，预热缓存合计约 7.5 微秒；投影结果一致。该样本仅是这段计算的耗时，不能换算为真机 FPS 或整体提速倍数。
3. **结算结果随动画反复布局。** 原结果 ScrollView、金额格式化和明细包在 60Hz 计时容器内；同一 550ms 区间，金额区域求值 33 次。当前只有标题和底部按钮消费动画相位，金额区域同区间求值 1 次，保存后的核对页也不再继续渲染。
4. **扫光结束改变排版。** 原版移除“跳过”按钮后增加标题宽度。在 300pt 窄屏、长英文名称和大字的增强宿主测试中，日期与主金额上移约 29pt。当前隐藏跳过控件但保留布局空间，标题、日期、主金额、按钮及上下文区域在尾段到完成的落位差均不超过 2pt；原 0.24 秒按钮起光与 1.8 秒扫光保持。

## 验证记录

- 原版完整流程及新增有截止期卡 8 轮短拖／完成下拉均通过，模拟器没有复现整页永久失去响应；它们不能否定真机偶发问题。
- 定向修复前：`/tmp/checkline-interaction-hosted-before.xcresult`，周期卡重复发布、金额区域每帧构建断言失败；初版布局用例未碰到长名称宽度边界。
- 同一增强布局用例的旧结果组件对照：`/tmp/checkline-settlement-layout-before.xcresult`，上下文宽度及标题、日期、主金额共 4 项几何断言失败，金额区域构建计数也失败。对照临时工程恢复实际旧 Outcome 实现，测试文件与修复后相同，只验证结果组件布局，不代表旧 App 全流程。
- 修复后定向：`/tmp/checkline-interaction-hosted-after.xcresult`，7 项测试通过（带参数用例展开 8 次）。原始日志有一次测试窗口切换的 UIKit appearance 提示；首次 fixture 因未保留 ModelContainer 发生测试宿主崩溃，已显式延长生命周期并保留真实 recordExpense 保存复验。
- 完整领域／状态：`/tmp/checkline-interaction-full-unit.xcresult`，311 项／63 suites 通过；包含历史 Prototype 测试，不以总数宣布完整产品验收。
- 原生完整 UI 与压力回归：`/tmp/checkline-interaction-ui-after.xcresult`，20 项通过、0 失败、0 跳过。5 项压力用例累计 30 次完成回程、62 次短拖取消；覆盖浅暗、截止期、快速／慢速、靠近阈值短拖、跨卡、后台恢复、球面切换和减少动态。另有一次心愿实付输入时的既有 `Invalid frame dimension` 提示，未改碎玻璃组件，不描述为零告警。
- 真机隔离 `Rex.Check-Line.MotionQA` /「CheckLine QA」4 项通过、0 失败、0 跳过，每项 1 次预热和 3 次采样；使用内存合成账本。卡库浅暗和补差额／越线均完成；XCTHitchMetric 检测值均为 0，但不能推断恒定 FPS。结算取画面平均约 49–50ms，单次最高 62.7ms；保存平均约 8ms，仅代表小型合成账本。CPU、物理内存和原始样本见 [phone-metrics.json](phone-metrics.json)。任务计时包括 XCTest 输入和空闲等待，不能当作动效时长。没有旧版真机对照或长时间热稳定性数据。
- [原速结算片段](settlement-after-1x.mp4)与浅暗卡库／补差额／越线截图取自模拟器实际流程；宿主几何测试另覆盖长英文和大字。手机短轮性能测量与模拟器视觉证据分别记录。

XCTest 默认在动作之间等待空闲；现有连续操作覆盖不等于同一触点反向拖动、回弹尚未结束时重抓或多指触控均已验证。真机持续性能、发热、iOS 17 和最终手感仍需分别记录。没有通过改变光点数量、浅暗材质、波面调色、截图分辨率或动效时长掩盖开销。
