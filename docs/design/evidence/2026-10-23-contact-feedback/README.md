# 插卡彩色流光与 CLICK 收尾修复

2026-10-23 Rex 指出手机插卡光效不再是获认可 HTML 的彩色流光，CLICK 结束后仍有隐约残影。基线为 [R34 快照](../2026-10-22-native-r34/approved-r34.html)，没有重新设计配色或改变金额规则。

## 原因与修复

- 原生旧版使用空间固定的紫／青／白渐变描画一小段路径，再整体模糊，丢失 R34 的粉色和随边缘运动的完整色带。恢复快照的紫／青／粉／紫 62° 角向光带、清晰描边和柔光两层；直接描画组件自身连续圆角，摘要从两块之间向外分流，票据从顶部向两侧下行，仍为800ms。
- 旧 CLICK 只按 TimelineView 的采样时间判断是否显示，结束任务把时间线暂停，却没有把显示条件关闭，可能保留最后非零透明度的一帧。现在由独立截止任务实际卸载整棵绘制子树，文字、底板、描边和冲击线一起消失；新的接触重建时间线身份，旧任务不能结束新的反馈。
- 彩带透明端保留自身色相，避免玻璃边缘出现暗尾；截止任务禁用隐式过渡。前台／后台及减少动态效果均参与有限反馈的生命周期。
- 保留接触日期，气泡、金额和文字各自继续使用原时钟。没有改动气泡生成、账本、持久化、网络、权限或任何结算计算。
