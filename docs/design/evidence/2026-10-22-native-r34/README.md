## 验收入口与路径

使用 Xcode 的 `CheckLine App` Scheme 运行持久化 App。隔离演示或 `-design-preview` 仅用于样例，不作为个人账本。下面动作无需阅读代码即可核对：

1. **预算首页：**左右甩卡，长按或上拖拔出，再轻点插入。检查卡口接触、CLICK、气泡与 0.8 秒光传导；数值和票据应同步到当前卡。插稳后轻点卡片进入详情。
2. **卡夹层级：**从卡夹边框上拖看记录，手指中途松开看回弹；从横向透窗下拖还原。再下拉看卡库，切换弧线／球面并拖动选卡。轻点拖动面应停在原层；明确上下按钮才处理轻点切层。
3. **心愿：**切未实现／已实现和卡片／横条，点卡翻面、点右上角展开。创建时连续换预设封面，切到“我的图片”再切回，名称等输入不能丢失或使整张抽屉重新入场。未填价格的卡片应禁兑。
4. **兑换：**用余额足够的示例心愿输入实际成交金额，勾选真实购买并确认。成功保存后才揭晓，完成后应在已实现列表；跳过／提前关闭也不能重复扣款。无封面以名称承接。
5. **结算：**对到期卡先核对记录并接受数据覆盖，再确认。净结余收币进入同页心愿余额，预算和周期保持原选择；有待恢复差额时先看补差额，只有净转入出现加钱动效。未到期只能预览。
6. **小朵：**主动打开并输入“想买耳机，1200元”，先查看心愿草稿，再确认添加；不能直接当消费保存，也不能在没有发问时自动恢复旧询问。
