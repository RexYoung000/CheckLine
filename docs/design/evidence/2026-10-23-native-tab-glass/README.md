# 紧凑底栏恢复原生玻璃切换

2026-10-23 Rex 指出底部原生玻璃切换再次丢失。1.0（15）将两页入口聚拢，却用了自有选中层，只完成了排版；本轮保留纯图标和紧凑布局，恢复真正的系统 TabBar。

## 实现

- iOS26及以上由独立 `UITabBar` 处理玻璃透镜、按住横拖和松手选页，SwiftUI 接收选择结果；没有自画现代系统选中层或修改私有视图。Apple 官方允许 [UITabBar 独立使用](https://developer.apple.com/documentation/uikit/uitabbar)。
- 两个 `UITabBarItem` 没有可见标题，保留预算／心愿本地化无障碍名称、按钮角色和选中状态。小朵仍为紧邻右侧的独立入口，关闭后保留原页。
- 可见双图标胶囊约130×60pt，小朵60pt、间距10pt，组合约200pt居中。宿主容纳系统额外侧留白及安全区，不能把控件的外框当成胶囊实际边界。iPad只为此窄控件指定compact尺寸类，不改变页面或设备身份。
- 根TabView继续保持两页状态，隐藏其内部栏，避免重复导航；详情与录入的显隐和原有返回机制保留。iOS17–25沿用已有材质回退，不称作新系统透镜。

## 运行证据

| 环境／具名路径 | 最终结果 |
|---|---|
| 402pt／iOS27：居中纯图标→心愿→小朵→关闭→预算 | 1/1；实际TabBar存在，只有三个按钮且没有可见文字，选中、名称、热区、可见载体居中和返回原页通过 |
| 同环境：按住预算横拖到心愿，再反向横拖回预算 | 1/1；系统触摸追踪松手提交，双向页面与选中状态一致，原速录像可见透镜随手指放大和移动 |
| 同环境：保存合成消费→打开／关闭小朵→切页 | 1/1；录入退出后底栏与原页保留 |
| 375pt／iOS26.5：英文、最大辅助字号、深色、应用减少动态开关 | 1/1；纯图标、触控热区、切页及小朵往返通过；此开关不代替系统级减少动态设置验收 |
| iPad mini／iOS26.5 | 1/1；最终窄控件目标约65×54pt，胶囊与小朵均居中且留有间距，切页／小朵返回通过 |
| Release 1.0（16）及真机测试包 | 构建通过，Release严格签名校验通过；安装与启动边界见下方手机记录 |

最终模拟器为主屏3/3、小屏1/1、iPad1/1，共4条不同UI用例、5个用例／设备组合；附加一次系统拖动原速录屏复测1/1。不重复计入旧版本测试，没有重跑金额领域全量测试，本轮未改变账本、金额、Schema、草稿、权限或模型服务。无障碍只检查名称、角色、选中和热区，没有完成本轮完整VoiceOver朗读验收。

初轮iPad使用常规尺寸类，系统将触控目标压到41×36pt，检查失败；为该控件指定compact后恢复54pt高度。随后截图发现iPad与iPhone的系统侧留白不同，原外框中心断言不能准确反映可见胶囊，改为测量首个按钮的玻璃内边距并核对截图；收正宿主宽度和侧留白，最终目标65×54pt、可见载体中心误差小于1pt，仍使用2pt公差，没有缩小最低44pt要求。主屏与小屏也使用最终代码重新运行通过。

## 手机记录

初次手机在编译期间锁屏，Xcode停在启动前等待；当时已取消等待任务，恢复Release并查询确认版本16，正常无参数启动被Locked拒绝。下面为Rex随后明确解锁授权后的实际补验，覆盖此前的待启动状态。

2026-10-23 17:16–17:18，iPhone 12隔离合成账本UI整组5/5通过，0失败、0跳过，执行约101秒；使用预编译1.0（16）测试包，未重新编译等待手机。

| 真机具名用例 | 实际支持的结果 |
|---|---|
| `testCompactIconDockStaysCenteredAcrossTabsAndAgent` | 纯图标、三个按钮、系统TabBar存在、载体居中、切页／小朵返回；预算和心愿热区各64×54pt |
| `testNativeGlassTouchTrackingSwitchesPages` | 实际按住横拖到心愿并反向拖回，页面与选中状态一致；不以端点截图代替完整玻璃运动观感验收 |
| `testSavingRecordAndClosingAgentPreservesNavigation` | 保存一笔合成消费，关闭小朵并切页后底栏保留，已检查实际结束截图 |
| `testRepeatedInsertionLeavesNoClickOrBorderResidue` | 两次拔出／插入后，卡底98×22pt的CLICK区域与初始待机像素差小于0.4／255；卡库往返通过，结束截图未见残留。该像素断言不覆盖摘要与票据整圈边缘 |
| `testAmbientBubblesContinueBeyondBurstAndWhileDetached` | 喷涌结束后相隔约3秒的卡面像素继续变化，已检查两张截图中均有气泡且位置不同；拔出后的截图仍有液体与气泡。没有采集拔出状态连续视频，不能单凭整卡差异独立证明气泡持续运动 |

测试完成后立即原位恢复同一签名Release 1.0（16），设备元数据确认`version=1.0`、`bundleVersion=16`；正常启动成功，启动参数为空，随后进程查询确认正式App运行。没有卸载、清账、读取个人账本／Keychain或重置配置，也没有真实模型请求。测试截图只来自隔离合成账本，正式启动后没有截取个人账本画面。

保存录入时有一条`Invalid frame dimension (negative or non-finite)`运行时警告；同一路径在之前1.0（15）及本轮模拟器也有记录，现有断言和结束画面未失败，不能称为无运行时警告。有限只读复核未确认调用点：录入字段未见负尺寸，背景首页有减法宽度候选；尚无证据将其归因于本轮原生Tab桥接，保留为待定位项，没有推测性改动。构建保留原有领域并发隔离／未使用变量及AppIntents元数据警告。系统减少动态效果、完整VoiceOver、真机帧耗时和最终手感／视觉仍待验收。
