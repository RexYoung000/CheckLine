## 已落地与验收路径

| 路径 | 预期表现 |
| --- | --- |
| 预算卡工作区 → 结算预估 → 待确认 → 消费详情 → 确认 → 逐级返回 | 始终使用选定周期，待确认数量和估算金额刷新，旧确认失效；未到期循环卡不出现正式结算提交。 |
| 小朵 → 核对摘要 → 编辑 → 切回 → 继续修改／继续 | 共用同一份金额、币种、商家、日期与归属；取消核对保留当前对话，关闭或重启仅恢复输入。恢复不自动保存，不以旧原文覆盖修正字段。 |
| 手动记一笔 → 展开附件 → 添加／查看 | 读取显示进度，失败可重试或移除；放大可缩放并返回原任务。已保存记录的附件失败只续存附件。 |
| 预算卡 → 卡片信息／历史周期 → 所选周期 | 信息与额度分组，只在允许时显示调整；历史显示该期实际结余／越线，原结算与调整按需展开，返回原目录。 |
| 心愿 → 添加／兑现 → 关闭重开 | 创建与按心愿隔离的购买草稿分别恢复；实际金额、币种与钱包影响可核对，真实购买确认必须重新勾选。 |
| 已实现心愿／心愿余额 → 变动记录 → 详情 | 展示购买日期、实际原币金额、钱包增减、换算依据及有效的关联周期／购买入口。 |
| 分析／设置 → 来源、隐私、关于 | 区分本期已用与近 14 天趋势；设置原位显示语言、基准币和动效状态，未接通来源折叠，关于展示当前版本。 |

草稿只保存用户输入、用户提供的汇率与明确添加的图片，不保存派生余额或旧购买同意。相册选择句柄只在当前面板内存保留；未读取成功的图片跨重启后需重新选择。读取／保存失败保留输入，条件变化重新核对。
