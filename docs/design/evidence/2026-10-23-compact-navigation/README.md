# 居中图标底栏

2026-10-23 Rex 要求移除预算／心愿Tab的可见文字，把两页入口与小朵向中间聚拢。本轮只调整原生底栏，未修改账本、金额、草稿或小朵服务。

## 结果

- 约200pt的整体居中；两页共用130×60pt玻璃胶囊，小朵为紧邻右侧的60pt圆形入口，中间10pt间距，不随屏幕宽度拉开。
- 使用既有预算／心愿图标及小朵。没有可见文字；本地化无障碍名称、选中状态与打开原任务的行为保留。Tab触控区域约60×50pt，小朵60×60pt。
- TabView继续承载两页，隐藏系统全宽底栏；玻璃和低版本材质回退复用原组件。选择页面即时更新，详情显隐、模态遮挡与原导航恢复机制保留。自有选中层不称作系统Tab透镜。

最终完整结果是主模拟器3/3、小屏1/1、iPad1/1，均无失败或跳过，共4条不同UI用例、5个用例／设备组合。未重跑全量领域测试；本轮未改变领域逻辑。无障碍只核对名称、按钮角色和选中语义，没有冒充完整VoiceOver朗读验收。
