## 入口与查看方式

- [浅暗并排交互稿](compare.html)：页面下拉包含 20 个入口，两侧可分别操作；可检查正常或减少动态效果。
- [独立交互稿](index.html)：顶部切换浅色／暗色，保留当前抽屉、输入和翻面；左侧可切换页面、示例状态、预览宽度与文字大小。
- [已确认 R3 原图](reference/r3-focus.png)、[矢量原稿](reference/r3-focus.svg)、[当时前后对照](reference/r3-before-after.png)。这些基准已归档进项目，不再只依赖临时目录。

当前本地服务：[打开浅暗对照](http://127.0.0.1:18873/compare.html?view=home)。从本目录运行 `python3 -m http.server 18873 --bind 127.0.0.1` 可重新提供同一入口。

建议先对照 R3 看右侧暗色首页的蓝光、主卡下缘的深色背衬和透色卡夹，再查看左侧浅色。继续检查详情、卡库、心愿、钱包和表单；在结算／兑换入口勾选示例核对后，可看到保存结果与奖励。所有操作仅影响本浏览器的隔离示例，不连接手机账本、模型或真实购买。

对照页切换“查看页面”或“减少动态效果”会重新加载两侧的演示入口；检查当前任务原位换主题，请点“单独查看”，使用独立稿的顶部主题按钮。

## 来源、采用范围与材质规则

- 页面结构、插拔／层级、弧线与球面卡库、心愿翻面、草稿、失败恢复、确认和奖励顺序继承 [已确认 R34](../../evidence/2026-10-22-native-r34/approved-r34.html)，内嵌资源与许可保留。没有引入新的 Web 运行时或第三方依赖。
- R3 的强蓝环境、深色背衬、透明表面、左上局部受光和接触阴影共同构成暗色版。不能用整体加白、统一描边或大范围柔光替代厚度。
- 首页光场按卡片插稳位置定位，随预览宽度与文字排版更新；拖卡时光场不跟着卡片飘移。前卡轮廓连续，后卡保留顶部透光，穿入前卡的硬边由前景玻璃柔化。
- 浅色版保留同样的受光与透色关系，以浅色矿物背衬、较轻阴影和墨色内容表达；不采用被否决 R2 的实心白色摘要及实色卡夹。
- 详情卡和卡库纹理有独立光场；心愿、钱包、输入与结果使用共享玻璃角色。全屏心愿／照片始终有深色聚焦环境与对应前景文字，避免浅色玻璃上的白字失去对比。
- 本轮只校准表现与局部排版。样稿仍沿用 R34 流程，原生后来扩展的全部卡上限编辑／提前结算规则没有在本轮重新实现，不能据此覆盖当前原生业务契约。

## 本轮验证

在 Codex 内置浏览器中完成，使用隔离合成数据：

- 390 × 844 对照框：20 个入口各检查浅／暗主题，保存对应画面及 DOM 记录；这是 **40 个页面状态的渲染与基础语义检查**，不是 40 项端到端测试。大部分目录画面使用减少动态效果，正常弧线与球面另查。
- 两侧正常弧线切球面，再点击返回卡夹；操作可达，卡面纹理跟随主题。减少动态效果使用原有可操作列表回退。
- 独立稿填写 `35` 与合成用途，浅／暗往返后面板和输入保留。模拟保存失败后，错误说明与输入保留；切浅色后重试保存成功并返回首页。成功反馈包含撤销入口；一次检查因反馈已超时未实际点击，不将其计作撤销验证。
- 两套主题分别经核对确认到达结算结果（净转入 120，余额 400）和心愿结果（实际 300，余额 300）。另执行正常揭晓途中切主题，结果仍为同一次已保存购买；正常收币／揭晓的后续检查见同目录证据。
- 320 预览宽度、1.6 倍文字：光照锚点随卡高更新。发现原有横向表单在大字时值区域收缩到不可见，已改为上下两行并复核商家、归属、日期和底部操作。768 预览宽度核对心愿多列布局。
- 本轮发现并修正详情卡独立光场被旧选择器覆盖、卡库亮区文字偏淡、浅色心愿大卡在暗遮罩上的对比度不足；修订后对受影响状态复查。

最终运行检查发现三条间歇性 `MutationObserver.observe` 目标异常；页面错误诊断与随后连续重载／切页未再捕获新的异常，尚未确定来源。画面、主题与本轮操作仍可完成，记录已保留，不宣称全程无控制台错误，也未猜测性改写原有观察器。

截图和语义记录位于 [evidence/](evidence/)，检查汇总为 [浏览器核对记录](evidence/browser-checks.json)。最终画面、手感由 Rex 验收；未验证原生系统玻璃、iPhone／iPad 真机、系统 VoiceOver、实际键盘、设备帧耗时或完整英文适配。没有运行原生构建／测试，也不将 HTML 结果视为 M4 验收关闭。
