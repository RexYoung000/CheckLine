## 本轮验证

### 2026-10-24 重点色与交互补正

本轮只修改 HTML，保留上一轮 R3 卡夹的单片透光面、局部光场、接触阴影与前后层次。24 类预设图标改用主题语义色；小朵分别重配浅暗的表面、暗部、反光和边缘色，保留原矢量造型及渐层。照片不参与重着色。奖励中的玻璃、银币、光流与受光边移除紫色残留，香槟金币保留。

Rex 明确确认「进度不足 100% 时，兑换入口直接置灰」。HTML 的状态与跳转如下；这是本轮样稿规则，不修改原生购买入口：

| 当前状态 | 入口与下一步 |
| --- | --- |
| 未定价／无有效报价／不足 100% | 原生 `disabled` 按钮，无边缘光；无效点击不穿透到翻面 |
| 达到 100% | 固定按钮热区并显示边缘光，点击进入实际购买核对 |
| 翻面中 | 临时锁定兑换，翻面落稳后重新按进度判断 |
| 实际金额或换算无效 | 核对页保留输入，不能确认 |
| 取消或关闭核对 | 保留购买草稿，返回原心愿 |
| 保存失败 | 保留金额、币种与核对内容，不播放成功动画；可重试 |
| 保存成功 | 只写一次变动，再播放揭晓／收币；重播只改变表现 |
| 跳过／关闭／尺寸变化／减少动态效果 | 结束当前动画，落稳同一已保存结果 |

卡背不再随鼠标倾斜，操作区不参与翻面；小卡按钮为 112×44px，大卡为 200×52px，大字时小卡至少 51px 高。按钮不扩张不可见热区。可兑换边缘光与草稿解耦；减少动态效果使用静态边缘光。

预算、心愿和小朵共用约 204×66px 的一片玻璃胶囊，每个入口约 63×54px。前两项保留页面选中状态，小朵声明打开对话面板且不显示页面选中态。这是可操作视觉提案，最终外观与手感待 Rex 验收。

在内置浏览器中实际完成以下有界检查，使用独立 `r37` 合成数据：

- 浅暗切换：全部 24 类预设图标改色，所选封面保留；小朵 10 个表面／边缘色分别配置，形状保留。购买输入和小朵输入原位切主题后保留。

### 卡夹材质验收后的定点补正

Rex 指出上一轮卡夹质感明显偏离 R3，并出现横线，视觉验收未通过。下方旧版 40 个状态的记录只说明渲染与流程可达，不能作为材质已还原的证据。本次补正包括：

- 旧前沿 SVG 与底板的半透明填充相互重叠，产生跨宽接缝；改为单片连续曲面，前沿只画一条受光边。该表面延伸至视口下缘，避免浅色版在底部再次硬截断。
- 卡尾保留在交互结构中，但取消外露的矩形涂层；槽口改为卡下的柔软接触阴影。主卡只保留一道渐弱边缘受光，摘要描边降为低浓度单线。
- 主卡恢复 R3 的 `300 / 352` 比例与较短顶部空隙。明暗分别锚定卡顶与插稳下缘，液体改为三段透明渐层和细亮边；后卡内容弱化，避免穿透后的文字与硬边争夺焦点。

- 详情卡和弧线／球面库纹理复用同一套环境光、反射与薄边缘参数，避免卡库退回均匀的蓝色实心渐层。
