# MutationObserver 空节点报错诊断

日期：2026-10-25。基准：`4cafea5`。

## 结论与边界

已将报错隔离到当前内置浏览器／自动化环境的新建 iframe 标签页流程，不能归为 CheckLine 业务观察器缺陷。尚不能读取宿主内部错误栈，因此未认定具体注入模块，也未修复宿主程序。项目 HTML、样式、业务脚本、动效参数及原生源码均未修改；没有加空判断、捕获吞错或覆盖全局观察器的正式代码。

## 复现对照

| 场景 | 实际结果 |
| --- | --- |
| 无 JavaScript 的单页 `control.html` | 新标签页未记录错误 |
| 无 JavaScript 的父页嵌入两个同样无脚本的子页 `frames.html` | 新标签页出现两条相同的 MutationObserver 非 Node 错误 |
| 临时动态创建 iframe、延至 DOMContentLoaded 后创建 iframe | 仍出现同类错误，延后挂载不是有效修复 |
| 在已有单页标签中导航至 iframe 复现页、重载已有对照页 | 本轮未增加该错误；说明首次创建与普通重载需要区分，不能把重载无错宣称为修复 |
| 同一份预算 HTML 单独打开 | 主要回归路径未记录 error / warning |

最小复现：在当前预览环境分别以**新标签页**打开 [单页控制](control.html) 与 [双 iframe 复现](frames.html)。两份文件均无 JavaScript。原始日志见 [runtime-audit.json](runtime-audit.json)。这不是普通浏览器兼容性结论，尚未在其他浏览器比较。
