# HTML 浅暗控件统一：实施与检查

基准：`edddecd`。入口：`budget-pages-pair.html?view=wish&study=ui-consistency-1`。原生 App 未修改，视觉待 Rex 验收。

## 本轮修改

- 浅色 Tab 透镜填充透明度减半，移除外投影；保留内反光、模糊、54px 按钮高度及冰蓝图标。暗色透镜不变。
- 心愿首页及购买完成页的余额恢复主要文字色；说明和币种维持次级色。
- 日历消费日用圆点，只有选中日铺冰蓝。补齐 320 宽度、160% 字号时七列溢出的问题，按钮高度不变。
- 移除各主题与子页重复的选中背景规则，统一由 selection-ui.css 管理。
- 小朵、预算金额、心愿预计金额、实际购买金额及币种组合使用单圈冰蓝焦点；抽屉手柄的焦点也跟随统一角色。

## 实际检查

通过 IAB 实际打开 21 个入口的浅暗版本，检查页面可达、主要文字／按钮／选中角色。不是每个业务分支的完整验收。运行样式和宽度记录见 [runtime-audit.json](runtime-audit.json)。

| 范围 | 已操作与观察 |
| --- | --- |
| 页面 | 首页、记录层、卡库、详情、消费记录／详情、日历、历史、信息、心愿／背面、钱包／变动、录入、新建预算、新建心愿、封面、小朵、设置、结算确认、购买确认，共 21 个入口 × 浅暗 |
| 控件 | 预算／心愿导航、未实现／已实现、卡片／横条、待确认筛选、预算一次性分段、耳机预设、弹层展开及关闭 |
| 日历 | 选择 24 日显示咖啡 ¥28；选择 23 日趋势柱显示地铁 ¥7；日期、趋势柱、列表同步，未选中消费日透明底且有圆点 |
| 输入焦点 | 小朵输入框和购买金额／币种：外层 2px 冰蓝，内部无重复描边；键盘 Tab、Enter 可完成相关控件操作 |
| 尺寸 | 390 标准浅暗；320 + 160% 字号检查心愿、日历、预算表单；768 + 160% 检查心愿与小朵。日历溢出修复后 scrollWidth 等于 clientWidth；对照页检查 440 纵排及 1280 并排 |
| 卡库和插卡 | 弧线／球面切换；拔出后显示未连接，插入后回到 seated 且摘要可操作；减少动态效果下从卡库选择周末出行可接通 |
| 心愿 | 余额 600／预计 1200 的 50% 入口置灰；预计 320 的 100% 入口启用并保留边缘光；中心和左右内侧命中测试通过，可进入购买核对 |
| 确认反馈 | 浅暗结算确认进入结算结果、购买确认进入心愿完成反馈；修正完成页金额后复测为主要文字色 |

确认操作仅在临时 HTTP 来源 `127.0.0.1:18874` 执行，与用户现有 `18873` localStorage 隔离。响应式测试临时副本仅开放原有预览宽度／字号控件并使用另一测试存储键；没有修改生产脚本。没有发送小朵指令、保存真实消费或操作原生账本。
