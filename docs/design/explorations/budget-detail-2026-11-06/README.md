# 预算详情 · 第一轮浅暗交互样稿

状态：2026-11-13 可操作浅深样稿。主要框架经 Rex 逐项确认，视觉与手感待审阅。11 月 6 日目录仅保留了说明，本版从仓库现存的冰蓝首页、液位卡和抽屉源码补齐可运行样稿。

入口为 [浅暗对照](compare.html)，单页为 [浅色首页](index.html?theme=light&view=home) 和 [深色首页](index.html?theme=dark&view=home)。直接打开 HTML 或在本目录启动本地静态服务即可。

本轮仅设计预算详情这一条路径。约四分之三屏抽屉支持上拉全屏和下拉返回。首屏以冰蓝液位卡、近期消费为主，列表按日期留白分组。新版试将日历、历史、信息放到近期列表之后，把「记一笔」收成中性色小按钮。液位卡随滚动收成预算名称和余量摘要，冰蓝逐渐退至中性色。消费详情在同一抽屉横向进入并逐级返回，恢复列表位置。新版布局与材质待审阅。

复用 `../material-themes-2026-10-23/budget-home.html` 的首页、心愿和真实材质／动效源码，构建器只在其副本注入本轮来源，不修改旧稿。原生 App、账本 Schema、服务和个人数据不变。旧稿里的录入、日历、历史、信息、结算与心愿等页面保留原样，不代表这些页面已完成本轮重设计。

重建：`node docs/design/explorations/budget-detail-2026-11-06/build.cjs`。

## 数据与范围

所有记录均为合成示例。沿用原稿预算 ¥3,000、暂计已用 ¥1,720、暂计剩余 ¥1,280，将其中一笔咖啡 ¥28 标为待确认；确认该笔不增加消费。原「日常支出」合成汇总被拆成多笔小额示例，总额保持，以检查长列表和返回位置。每次打开审阅状态重新建立内存示例，不读写旧稿存储或真实账本。

金额沿用原稿整数最小单位与已有演示门禁；正式 App 的 Decimal 领域服务仍是业务事实来源。原稿没有原生后续扩展的全部周期／提前结算能力，本轮的提前结算入口只到核对预估，不提交或修改周期。到期结算仍可使用原稿已存在的确认和结果。小朵、汇率、权限、照片等未在本轮扩展为真实服务。

## 验收路径

1. 首页点「这个月」→详情→上拉／点拉手全屏→滚动查看摘要→返回首屏。
2. 查看全部→筛选待确认→点消费→返回，保持筛选和位置；可确认归属，再返回查看金额与状态。
3. 记一笔→输入合成金额→取消／恢复草稿或保存，返回同一预算；保存后余量刷新。
4. 切换到期待结算、无记录、小屏／大字、减少动态状态，核对操作可达与返回。

本次用 EgoLite 在 390 × 844 的浏览器视口实测浅色与深色：首页点卡、展开抽屉、连续滚动、打开咖啡详情、返回原滚动位置和焦点、滚回完整卡面。另跑了减少动态效果、空记录和 320 × 640 到期大字状态。当前证据覆盖这些浏览器路径，原生手势和真机体验仍待验证。
