# Cloud Agent 小样来源

- 来源：[jeremy-prt/bloub](https://github.com/jeremy-prt/bloub)
- 固定版本：`b4bb3c1b5f93c7b87a2e8d620f667c4093d97749`
- 采用范围：`src/bot/skins.ts` 的 Cloud Shape 五个圆形参数、64 点径向采样与归一化，以及 `src/bot/shape.ts` 的圆形并集与闭合曲线构造。
- CheckLine 适配：纯二维灰紫配色、独立五状态姿态函数、连续中断、循环／单次节奏与审阅界面；未引入 Vue、第三方运行时、网络服务或 Spine。
- 用户已选择 Cloud Shape 作为首版形象。动作与配色为待审阅提案；此材料只用于内部设计探索。上游 README 声明 MIT 覆盖仓库代码，不覆盖其模仿的 x.ai 设计；本记录不宣称品牌／形象权利已完成正式发布核查。
