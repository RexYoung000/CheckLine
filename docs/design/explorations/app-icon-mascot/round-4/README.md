## 本轮设计 brief

依据 `PRODUCT.md` 的「给自己划一条线，线内自由」与 `DESIGN.md` 的「克制、温柔、有边界、可信」。保留已确认的紫色家族、柔和轮廓和中性底色。桌面图标只建立一个主要记忆点，三个候选分别验证名称、角色和主动检查的表达；它们不是三种材质或姿态。

| 方向 | 构图 | 对产品的解释（设计推断） | 尚待判断 |
| --- | --- | --- | --- |
| A 名称标记 | 柔和开放的 C，下臂横向延伸为一条线 | C 对应 CheckLine；平直收口和开放留白表达温和的边界 | 名称关系最直接；是否过于字母化，以及独特性是否足够 |
| B 小朵符号 | 单一简化云形，双眼留白，底部平稳 | 由角色建立亲近感，以轮廓呼应柔和边界 | 名称关系较弱；是否希望桌面品牌以 Agent 为主角 |
| C 勾线 | 勾的长臂接一段水平线，组成单一笔画 | Check 是用户主动检查与确认；Line 是自己设线 | 容易被理解成待办，不能仅靠符号就声称预算语义明确 |

SVG 均为本轮直接绘制的原创矢量构图，不是第三方图标包或生成图片。资源以 1024 × 1024 坐标组织：`a-checkline.svg`、`b-xiaoduo.svg`、`c-check-line.svg` 是有不透明背景的构图；`a-mark.svg`、`b-mark.svg`、`c-mark.svg` 是同一轮廓的单色透明底标记。图标画布本身不预裁圆角，网页仅以 CSS 遮罩展示。

本轮先判断轮廓与名称关系。颜色数值、轮廓比例均为当前可见候选值，不视为已批准 Token。正式生产仍需确定轮廓、对照系统网格、制作所需外观与分层资源、检查系统实际裁切及真机主屏；不据 SVG 或浏览器截图宣称已经完成。

已在内置浏览器默认 470 px 宽度实际查看：18 个图片实例全部加载，页面无横向溢出；60 / 32 px 缩略尺寸与 28 px 品牌签名尺寸实测一致，控制台无错误或警告。浏览器未调整视口；[实际截图](comparison.jpg)保存完整对照。SVG XML、资源引用与差异格式检查通过，没有原生代码或金额规则变更，未运行业务或 UI 测试。

当前结论仅是三个方向已可见。A 最贴名称，但仍要精修到不只是普通 C；B 更贴亲近的角色；C 的待办联想风险较明显。待 Rex 选定品牌重心后继续细化，不把这一轮平面初稿说成成熟品牌成品。
