# 结算彩光 · SwiftUI 动效试样

使用 Libraries.dev 的 [DistortionWavesKit](https://libraries.dev/waves)，在 iOS 17+ 的独立 SwiftUI 工程里试「结算核对 → 结算完成」。确认按钮的位置和触点决定 `.vertical` 彩光的起点。波峰从底部上扫，完成金额出现在原位，余光沿屏幕圆角消散。

示例为本期结余 ¥120，先补待恢复差额 ¥70，净转入心愿钱包 ¥50，钱包余额由 ¥280 变为 ¥330。勾选接受当前数据后才能确认。示例确认只改变本次试样的内存状态，重试和重播使用同一组数据。减少动态效果展示淡入淡出，大字或较矮的窗口使用可滚动的静态结果。

用 Xcode 打开 `SettlementWaveStudy.xcodeproj`，选 iPhone 模拟器运行。勾选「我接受当前数据，继续结算」，点击「确认结算」。点「再试一次」回到核对。试样使用 MIT 授权的原包，Swift Package 锁定试跑版本 `387b049ca8fe97b5d72999b5bf61a19ab1ccff81`。

## 本机验证

Xcode 27.2 构建成功，官方 `default.metallib` 已随试样打包。iPhone 17 Pro／iOS 26.5 模拟器的三条 UI 验证通过，覆盖首次确认、未勾选门禁、保存失败后重试、结果金额、返回重试和减少动态效果。减少动态效果通过 `--reduce-motion` 启动参数进入与系统设置共用的淡入淡出分支。录屏取自保存失败后重试成功的一次原速播放。

本次用 `main` 的固定提交复现动效。结果金额和余额均为合成示例，真机观感、系统减少动态效果开关、iOS 17 实机和正式 CheckLine 结算接入待验证。
