# 2026-10-01 整体 UI / UX 实施与验证

本轮按已确认方案完成当前本地功能的体验重整，保留四 Tab、液位预算卡、紫色材质和小朵。导入和新增管理 / 纠正只有隔离设计状态，不宣称真实能力接通。M4 保持开放，最终真机视觉与使用体验由 Rex 验收。

## 已实现与入口

| 场景 | 当前行为与验收路径 |
| --- | --- |
| 统一任务 | 右侧小朵 / 功能菜单「记一笔」进入同一面板，内部切 Agent / 手动；固定标题、滚动正文、操作区。建议与对话按需展开，复杂确认与大字号扩展。 |
| 创建预算卡 | 预算页默认名称、额度、币种、周期表单，显示实际生效日期；首页首张卡保留 Agent 优先，可请小朵帮填或切手动。 |
| 手动记一笔 | 金额 / 币种、商家、归属、日期默认显示；备注、原文和明确添加的附件渐进展开、显示数量。键盘有「完成输入」。iPad 使用停靠数字 / 符号键盘。 |
| 任务恢复 | 关闭、切换、重启恢复本机草稿，按任务 / 预算 / 周期隔离；Agent 重开恢复最后任务，明确聊当前卡才换上下文。额度编辑仅恢复输入，重新生成影响预览。 |
| 提交和续传 | 保留明确币种及原始金额；缺少换算不能错误绑定或算作零。稳定实体 / 附件 ID 支持重复确认、保存后中断和附件失败重试；全部完成才清理草稿。 |
| 卡片工作区 | 首页 / 预算点卡进入完整页面，隐藏根底栏；概览 → 记录 / 日历 / 历史 / 信息与管理逐级返回，退出恢复原 Tab 与卡片位置。 |
| 目录与详情 | 目录显示周期、状态、待处理数；记录按日期分组、筛选待确认。详情显示原金额、币种、日期、归属、来源、状态；可确认当前归属，处理后回到原筛选。 |
| 历史和金额门禁 | 历史显式指定周期，结算结果及后续追溯分开显示，不使用当前钱包代替历史结果。已结算记录确认走全屏影响页；现有额度编辑、结算、心愿兑现与撤销继续走原确定性服务。 |
| 数据来源 | 功能菜单 / 设置 → 数据来源：准确列出本地文字 / 手动能力与尚未接通的来源。Demo 的隔离导入 / 纠正覆盖正常、空、处理中、失败、影响确认及结果。 |

草稿保存在本机 Application Support，排除系统备份；用户明确添加的图片先去元数据，再按稳定 ID 保存。字段与图片分离，连续输入不反复写整组图片。完整对话只在当前会话，不启用网络、iCloud、Speech、Vision 或被动来源。

## 修复与复测

- 初轮返回隐藏底栏未恢复：根 NavigationPath 归零时复位详情状态，并阻止调试预览反复自动打开；原 Tab / Agent 与工作区返回重跑通过。
- 模式切换定位重复、未发送追问未进入表单：隐藏任务后方根页面的辅助功能元素，切换时解析明确字段；不再关闭旧面板再打开新面板。
- 恢复初始化曾覆盖已有草稿、当前卡和旧任务上下文串用：增加初始化保护、按周期隔离与最近任务指针；重启和多卡测试通过。
- iPad 浮动数字键盘遮挡保存：改用停靠数字 / 符号键盘，并提供完成输入；SE 大字号正文额外裁切，避免字段露到保存区后面。换算提示仅在选择异币种预算时呈现。
- VoiceOver 初次操作受开启后点击规则及跨测试状态影响：改用实际双击，测试显式启用 / 关闭；保存及朗读取得通过证据。
- 最后 UI 提示调整曾出现一次预算周期字典取值编译错误，已改为稳定 ID 取值，重新构建及测试；没有把失败运行计为通过。
- Xcode 三次用例通过后卡在可选模拟器诊断收集；仅终止对应诊断子进程后结果包正常完成，Xcode 仍报告成功。后续定向运行禁止可选诊断收集，未跳过任何断言或测试。

## 尚待验收与能力边界

- 本轮未安装或操作物理 iPhone / iPad；真机玻璃材质、连续触摸冲突、正常速度手感、帧耗时与最终审美仍待 Rex。模拟器操作与 VoiceOver 不能代替真人使用。
- iOS 17 兼容路径只经最低目标编译，本轮没有 iOS 17 运行时；超出 accessibility-medium 的极端大字、所有横竖屏组合及完整 VoiceOver 焦点巡检尚未逐页覆盖。
- 导入、来源连接、真实解析、多笔去重核对，以及完整记录编辑 / 删除 / 纠正仍未接入本次正式能力。隔离演示不写账本、不调外部服务；接通后另验功能。
- Release 保留既有两处领域方法 actor 隔离警告与一处未使用预览警告；本轮数字反馈辅助方法的隔离警告已消除。没有以构建通过宣布工程警告全部清零。

Rex 可按「预算页创建 → Agent / 手动切换 → 关闭并重开 → 点卡工作区 → 待确认记录 → 确认归属 → 逐级返回 → 额度预览 / 取消 / 保存 → 结算」试用；隔离导入与纠正从 Demo 的数据来源页进入。
