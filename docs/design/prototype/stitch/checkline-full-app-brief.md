# CheckLine 当前版本 Stitch 生成 Brief

> 历史说明：本文是 2026-07-06 阶段用于生成 Stitch 原型的输入快照，其中固定颜色、字号、边距、组件和参考项目只对该次生成有效。现行设计规则以 `../../DESIGN.md` 为准。

> 这份 brief 用于生成 CheckLine 当前版本高保真原型。
> 当前版本只覆盖预算钱包主线：预算、记一笔、统计、设置和结算。
> 心愿功能后置，不进入当前原型。

---

## 一、生成目标

为「预算线 CheckLine」生成一套 iOS App 当前版本高保真原型。

主参考项目：

https://stitch.withgoogle.com/projects/11707032164273888537

要继承旧「预算钱包」项目的浅色卡片、横滑钱包、分组列表、简洁统计和安静设置页。

不要继承旧项目的真实头像、真实姓名、真实账户余额、AI 智能记账建议、旧品牌文案。

---

## 二、输出范围

必须输出 8 个核心页面：

1. 首页
2. 预算列表
3. 预算详情
4. 新建 / 编辑预算
5. 记一笔弹窗
6. 统计概览
7. 消费记录日历
8. 我的 / 设置

可选输出：

- 结算清单
- 结算完成反馈
- 教程卡片
- 空状态页面（无预算、无记录、无统计数据）

不要输出：

- 心愿列表
- 心愿详情
- 心愿达成反馈
- 结算转心愿分配
- 任何真实账户余额页面
- AI 智能记账建议页面

---

## 三、产品心智

| 维度 | 内容 |
|------|------|
| 中文名 | 预算线 |
| 英文名 | CheckLine |
| 一句话定位 | 给自己划一条线，线内自由，线外克制 |
| 核心隐喻 | 「线」= 边界 + 检查点 |
| UI 容器 | 预算钱包，每个钱包对应一个独立预算 |
| 当前闭环 | 创建预算 -> 记一笔 -> 结算 -> 统计回看 |

当前版本核心：

1. 预算 = 时间 + 主题
2. 多预算平等并存
3. 支出 = 预算消耗
4. 结算 = 阶段性回看
5. 钱的决定权归用户

## 六、组件规则

- `BudgetCard`：白色卡片，24pt 圆角，轻阴影，展示预算名、剩余金额、进度、分类摘要。
- `BudgetBar`：6pt 高胶囊进度条，蓝色为默认进度，接近边界用黄色，已用完用红色加文案。
- `BudgetTagChip`：平等多选预算标签，选中态蓝底白字。
- `CategoryPill`：分类标签，视觉可小，但点击区域必须至少 44pt。
- `FloatingCaptureButton`：右下角主蓝圆形按钮，图标 plus，accessibility label 为「记一笔」。

---

## 七、文案规则

必须用：

- 预算线
- 预算钱包
- 记一笔
- 记下这笔
- 已用
- 最近记录
- 这个预算快用完了
- 结余

禁止用：

- 扣血
- 记账
- 主预算 / 副预算
- AI 智能记账建议
- 总资产
- 账户余额
- 转到心愿
- 离心愿近了

---

## 八、无障碍底线

- 所有图标按钮必须有清晰 label。
- 金额要能读成完整金额文本。
- 进度条必须提供百分比或文字辅助。
- 所有可点击区域至少 44x44pt。
- 颜色不能单独承担信息。
- 文字不能在卡片、按钮、底部导航里重叠。

---

## 九、交付判断

生成结果合格条件：

- 一眼能看出这是浅色预算钱包工具。
- 首页主焦点是当前预算钱包，不是营销页。
- 底部没有心愿 Tab。
- 页面里没有心愿列表、心愿详情或心愿达成。
- 页面里没有「扣血」。
- 页面里没有「AI 智能记账建议」。
- 页面里没有真实账户余额或真实用户信息。
- 统计页服务预算回看，不像复杂财务报表。
