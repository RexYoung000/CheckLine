## 需要继承的部分

- 一眼看懂当前钱包状态。
- 浅色背景 + 白色卡片。
- 卡片和列表干净，信息不堆。
- 操作入口克制，不在首页放太多按钮。
- 统计页用大数字和简洁图表，不做复杂财务报表。
- 设置页用分组列表，安静、清晰、可扫读。

## 不能继承的内容

- 不能把 CheckLine 做成真实账户余额工具。
- 不能使用「AI 智能记账建议」作为核心卖点。
- 不能出现真实用户头像、真实姓名或真实 ID。
- 不能让「钱包」压过「预算线 / CheckLine」品牌。
- 当前版本不能出现心愿列表、心愿详情、心愿达成反馈。
- 用户可见界面不能出现「扣血」。
