## 产品目标

「预算线」是基于「时间 + 主题」双维度的预算控制 + 心愿激励 App。

- 让用户通过**多预算并存**管理不同生活维度的支出
- 用**结算高光仪式**把「克制消费」翻译成「离心愿更近一步」
- 用**关联账识别**解决一笔消费归属多预算的复杂场景
- 通过多录入入口（Widget / 截图 / 语音）把记账摩擦降到最低

## 目标用户

- 有稳定收入，每月有结余，想攒下来做某事（旅行/相机/课程）
- 用过记账 App 但坚持不下来（只记不控）
- 已在用支付宝小荷包 / 多银行卡做物理隔离式预算
- 看重审美调性，不愿意用财大气粗类工具
- 市场：中国大陆 + 海外

## 用户任务地图

| 频次 | 任务 | 核心场景 |
|------|------|---------|
| 首次 | 创建第一个预算 + 心愿 | 选模板 → 设周期 → 分类 → 预设心愿 |
| 每日 | 记一笔 | 多个入口：手动 / Widget / 截图 / 语音 |
| 每周 | 看预算状态 + 心愿进度 | 主屏 C 位：当前预算剩余 + 心愿进度条 |
| 每周期 | 结算 | 关联账确认 → 心愿分配 → 结算高光 |
| 不定 | 心愿达成 | 全屏庆祝动画 + 分享 |

## 平台约束

- **主平台**：iOS 17+ / macOS 14+（SwiftUI multiplatform）
- **数据**：SwiftData + iCloud 同步
- **iOS 独占**：锁屏 Widget、Live Activities、截图 OCR、语音
- **macOS 独占**：菜单栏速记、全局快捷键（v1.1）
- **真人限制**：作者只有 Mac，iPhone 靠借测试机
- **iOS 硬限制**：无法自动捕获支付宝/微信支付（不走安卓无障碍服务路线）
- **语言**：中英双语，国区显示「预算线」，海外「CheckLine」

## 设计成熟度

**MVP**。第一轮目标是：「作者自己每天用得起来」。

允许：
- 视觉方向定调但不追求像素级
- 动效有基本版本（扣血 / 结算高光）
- 暗黑模式跟随系统，不精修

要求：
- 首屏一屏看懂（主预算状态 + 心愿进度）
- 记一笔 ≤ 3 步
- 结算高光必须和心愿达成一样有仪式感（品牌心智）

## 关键约束

- 不依赖第三方 UI 框架
- 配色克制（主色 + 中性色 + 庆祝色）
- 卡片为主，圆角统一
- 进度条/仪表盘是核心视觉语言
- 用户视角文案，不工程师视角
