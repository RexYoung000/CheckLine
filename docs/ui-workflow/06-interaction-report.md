| 交互 | 触发 | 动效 | Haptic | 时长 |

## 二、状态转换

### 2.1 扣血状态机

```
[idle] ──tap + ──► [capturing] ──确认扣血──► [deducting] ──动画完成──► [idle]
                        │                        │
                        └──取消──► [idle]         └──超支──► [overrun warning]
```

### 2.2 预算生命周期交互

```
[创建中 draft]
  │  用户完成创建 → 动画过渡到主屏，新预算卡片从底部滑入
  ▼
[进行中 active]
  │  用户记一笔 → 扣血动效 → 进度条更新
  │  到期触发 → 自动弹结算清单（重复型）/ 提醒通知（单次型）
  ▼
[结算中 settling]
  │  用户确认关联账 → 分配心愿 → 点击「触发结算高光」
  ▼
[高光动画]
  │  800ms 后自动过渡
  ▼
[已归档 archived] / [自动新周期 active]
```

### 2.3 心愿达成状态机

```
[active] ──累积≥目标──► [达成动画 1200ms] ──► [achieved]
                                                    │
                                          自动弹「开新心愿？」引导
```

## 三、空状态 / Loading / 错误

### 3.1 空状态

| 场景 | 视觉 | 文案 |
|------|------|------|
| 首次启动（无预算） | 深空背景 + 大号 + 按钮 | 「还没有预算？花 1 分钟设第一个」→ [创建预算] |
| 无心愿 | 心愿区空白卡片 + 按钮 | 「省下的钱去哪？设个心愿吧」→ [设个心愿] |
| 无流水记录 | 预算详情列表空 | 「这个预算还没有记录。记一笔吧」 |
| 无关联账 | 结算清单关联区隐藏 | — |

### 3.2 Loading

| 场景 | 方式 |
|------|------|
| 首次启动 | 品牌 logo + 淡入动画 |
| 数据同步 | 骨架屏 shimmer（卡片形状占位 + 微光扫过） |
| 截图 OCR 识别 | 识别中旋转指示器 +「正在识别金额…」 |
| 语音解析 | 波形动画 +「正在听…」 |

### 3.3 错误

| 场景 | 处理 |
|------|------|
| iCloud 同步失败 | 顶部横幅「同步暂时中断，数据已保存在本地」→ 自动重试 |
| OCR 识别失败 | toast「未识别到金额，请手动输入」→ 退回归类弹窗 |
| 语音解析失败 | toast「没听清，再说一次？」 |
| 数据冲突 | 静默解决，最后写入胜利（SwiftData 默认策略） |

## 四、手势与键盘

### iOS

| 手势 | 作用 |
|------|------|
| 右滑返回 | 标准 navigation 返回 |
| 下拉 | 刷新主屏数据 |
| 长按预算卡片 | 快捷菜单（结算/编辑/删除） |
| 长按心愿卡片 | 快捷菜单（查看详情/编辑） |
| 下拉关闭 | 归类弹窗 dismiss |

### macOS

| 操作 | 作用 |
|------|------|
| ⌘N | 记一笔（全局快捷键，v1.1） |
| ⌘⇧L | 速记弹窗 |
| ⌘, | 设置 |
| Tab | 归类弹窗内字段跳转 |
| Enter | 确认提交 |

## 五、可访问性

- Dynamic Type 全支持（从 caption 到 display 缩放）
- VoiceOver：所有金额读为「×× 元 ×× 分」
- 对比度：深色模式下文字满足 WCAG AA（4.5:1）
- 触控目标：最小 44×44pt（iOS HIG）
