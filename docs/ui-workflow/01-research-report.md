## 二、Copilot Money 设计语言提取（核心参考）

Copilot Money 是 Apple Design Award 入围者，证明了「数据密集的金融 UI 可以很美」。

### 2.1 深空画布系统

```
层次          颜色          用途
Canvas     #000814        主背景（近黑海军蓝）
Card       #001533        轻微浮起表面
Elevated   #00204D        模态/面板
Recessed   #010D1E        凹陷区域
```

**核心理念**：深色画布让数据成为视觉焦点。从不用纯黑 #000000，海军蓝比纯黑更温暖。

### 2.2 语义色彩系统

| 语义 | 颜色 | 用途 |
|------|------|------|
| 收入 | `#00CC4B` 绿 | 正向变化 |
| 支出 | `#FF4433` 红 | 消费/警告 |
| 净值 | `#1C6CFF` 蓝 | 品牌主色 |
| 待处理 | `#FECE4C` 黄 | 提醒/警告 |

### 2.3 排版策略

- 文字 90% 白（`rgba(255,255,255,0.9)`）而非纯白 → 减少长时间查看的视觉疲劳
- 显示标题 112px + `-2.24px` letter-spacing → 金融数据作为建筑结构体
- 次级文字 `#7F8BA4` / `#597CAA`

### 2.4 对预算线的启示

| Copilot 模式 | 预算线如何借鉴 |
|---|---|
| 深色画布+亮色数据 | 主屏的预算剩余大数字、心愿进度条可以用这种对比 |
| 图表即界面 | 扣血进度条不应该是装饰，应该是主交互层 |
| 渐进式信息披露 | 首屏只显示核心数字，详细数据点进看 |
| 语义色彩统一 | 扣血=暖色消耗, 结余=冷色积蓄, 心愿达成=金色庆祝 |
| 文字透明度防疲劳 | 90% 白替代纯白 |

## 三、YNAB 的经验与教训

### 可借鉴
- 进度条是核心视觉语言（预算消耗进度）
- 零基预算的心智（虽然预算线不做零基，但视觉语言可参考）
- Siri 集成、Widget 支持

### 应避免
- 用户抱怨「UI 改动太频繁」—— 说明常改 UI 会伤用户信任
- 「iPad 版太幼稚」—— 不要为不同平台牺牲设计成熟度
- 视觉杂乱——浮动添加按钮、多处红色通知同时出现

## 五、设计模式总结

### 适合预算线的模式

1. **进度条即界面** — 预算条的扣血可视化是主交互层
2. **深色优先** — 暗黑模式是第一公民，不是附加
3. **语义色彩** — 扣血 / 结余 / 庆祝 三套色彩语义
4. **卡片式布局** — 预算卡片、心愿卡片，圆角统一
5. **大数字 C 位** — 剩余金额像 Copilot 那样做大、做醒目
6. **渐进披露** — 首屏只看核心，点进去看详情

### 应避免的模式

1. 表格/列表为主的布局（像电子表格）
2. 过多通知图标（YNAB 用户的抱怨）
3. 浮动按钮遮挡内容
4. 平台风格不统一
