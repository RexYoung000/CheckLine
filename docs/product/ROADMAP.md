# ROADMAP — 预算线 CheckLine 节奏

> 节奏遵循「MVP 先行 → 迭代精致」逻辑。
> 当前版本先把预算钱包主线做顺，心愿系统后置。

---

## 一、第一轮 · MVP（预计 3-4 周）

**目标**：跑通「创建预算 → 记一笔 → 结算 → 统计回看」闭环，让作者自己每天用得起来。

当前体验样机沿用浅色预算钱包基线；外部参考只用于追溯设计过程，不作为实现或验收标准。

### 1.1 必备能力

当前执行切片：先把已收敛的 HTML 原型迁成使用内存示例数据的原生 SwiftUI 体验样机，验证四 Tab、预算钱包、记一笔、统计日历和结算手感；随后再进入 SwiftData、领域服务与测试驱动的正式 MVP 实装。体验样机完成不勾选下方正式 MVP 验收项。

| 模块 | 范围 |
|------|------|
| **预算创建** | 模板选择 / 周期类型（重复 + 单次）/ 起止时间 / 总额 / 分类设定 / 超支策略 |
| **多预算并存** | 多个独立平等的预算容器、明确的当前上下文与独立预算消耗 |
| **记一笔（手动）** | App 内 + 号入口、归类弹窗、平等多预算标签选择 |
| **预算消耗视觉** | 预算条和金额更新动效 |
| **结算清单** | 重复型 / 单次型双轨；总支出 / 结余显示；关联账确认（基础版） |
| **统计回看** | 月度概览、预算 vs 实际、分类分析、消费记录日历 |
| **我的 / 设置** | 预算设置、记录管理入口、通知/外观/隐私入口 |
| **数据持久化** | SwiftData 本地存储 |
| **数据管理** | 预算删除、消费记录单独/批量删除、共享消费安全确认 |
| **教程系统** | 预算线、多预算、记一笔、结算的基础教程 |

### 1.2 验收标准

- [ ] 作者本人能用预算线管理一个完整月度生活预算
- [ ] 同时跑一个单次型预算（如周末出行）
- [ ] 一笔多属场景能正确计入多个预算，结算时能正确确认归属
- [ ] 预算结束后能看到总支出、结余和结算结果
- [ ] 统计页能按预算和日期回看记录
- [ ] SwiftData 本地存储可用
- [ ] 删除预算或消费记录时，共享消费不会在未明确勾选的情况下从其他预算消失
- [ ] 全部 Core/Services 单测覆盖，绿
- [ ] 国区显示「预算线」、其他区显示「CheckLine」

### 1.3 不做（推到后续）

- 心愿列表 / 心愿详情 / 心愿达成动画
- 结算转心愿分配
- 截图识别、语音录入、Lock Screen Quick Capture Widget
- 分享扩展 / Shortcuts 自动化
- Widget 正式实现
- macOS 独占特性（菜单栏 / 全局快捷键）
- 付费墙
- 暗黑模式精修

## 二、第二轮 · 录入加速与视觉精修（预计 2-3 周）

**目标**：把日常记录摩擦再降一倍，把视觉提到产品级。

### 2.1 录入入口扩张

- **Lock Screen Quick Capture Widget**（iOS）：锁屏一点直进归类弹窗
- **截图识别录入**：Photos + Vision OCR 抓金额，弹归类弹窗
- **语音录入**：Speech + 端侧 AI 解析，「打车 38」一句话搞定

### 2.2 视觉精致化

- 基于 CheckLine 设计原则完成品牌视觉定稿；浅色预算钱包是可继续验证的当前基线，不是永久限制
- 预算消耗动效细节：进度条、分类小条、Haptic 节奏统一打磨
- 结算完成反馈二刷
- 空状态 / Loading / 错误状态
- 暗黑模式基础适配

### 2.3 体验细节

- 关联账确认页：批量「都算 / 都不算」等更顺手的操作
- 预算用完温柔提醒：文案 + 节奏 + 通知静音规则
- 通知策略：预算还剩 30% / 结算到期 / 新周期开始
