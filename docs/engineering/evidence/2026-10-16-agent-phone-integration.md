- 当前 API release `/opt/checkline-agent/releases/20261016-phone-e44dae01ed`，部署包 SHA-256 `e44dae01ed23d50601355226ab4c977d88ba178e6b61913a0406543e8727a2af`，保留前一 release 和配置备份。相对初次内部部署，增加测试凭据到期校验；服务端格式错误拒绝启动，到期请求在调用模型前返回 401。
- `CloudAgentSettings` 将限时服务凭据导入 Keychain（解锁可用、仅此设备），传输文件处理后删除；凭据不写入二进制或 UserDefaults。测试到期 **2026-10-23 14:37:53，北京时间**。首次发送选择云端或继续本地，设置可关闭；启动不自动请求模型。未配置的其他安装仍是本地模式。
- 原生先保留完整候选再合并同一任务。金额、日期、商家等纯字段回答在本机继续，选择预算使用稳定本机 ID，并按消费日重新计算周期／队列；不将首页焦点或单一候选自动当作归属。目标卡选择不改变原草稿作用域。模型 ID 不执行，所有云端消费本轮均先显示摘要确认。
- 失败保留输入，认证、限流、超时及不可用分别提示；不静默采用本地猜测写入。编辑、模式切换、任务切换、关闭与后台取消请求，并通过任务快照／请求代次忽略旧结果。原币继续传入领域服务；没有可用换算则阻止保存，不把缺汇率当零。
- 删除先选择本机记录并核对影响，再调用已有删除能力；已结算、心愿购买和含关联退款的普通删除不开放。结算、额度与兑现进入现有原生页面完成门禁。退款、已保存消费修改、多笔拆分和复杂追溯没有因此新增真实业务。

## 验收入口与仍开放项

iPhone 打开 CheckLine → 右下小朵 → 输入“记一笔午餐” → 选择“启用并发送” → 补金额 → 选择预算卡 → 核对并确认。可再试“昨天咖啡 12 元”，日期使用设备日历、归属继续核对；设置可关闭云端。

海外、手机 Wi-Fi／移动网络下实际模型对话、真机端侧语音、完整无障碍／小屏／大字号／深色／iPad 云端链路及最终使用体验尚未验收。本轮未重复整个环境矩阵，没有测试 Docker。自动实时汇率服务、公开用户身份与凭据轮换、第三方数据处理约定及公开上线仍另行实施。49 个隔离 HTML 案例不能用来宣称这些原生能力已交付；M4 和 Rex 验收保持开放。

回退可先在 App 设置关闭云端；服务器可停用 `checkline-tls` 并保留证书／源码／凭据，或将 API `current` 原子切回 `previous` 后重启。不得卸载 App 或清空账本来排查连接。
